# v0.6 UX design (Figma)

The approved design for the v0.6 UI. **No UI production code (plan Tasks 8–14) is written until this file records the owner's approval.** A change to an approved screen goes back through Figma first.

- **File:** [WAR-2D v0.6 UX](https://www.figma.com/design/JrMColnJiQbFfODqyPjBYf)
- **Status:** in progress (every screen approved; UI scale variants and flows awaiting review, then the version name)

## Tokens

Figma variables map one-for-one to `Theme.uss`: the variable `color/surface/panel` is `--color-surface-panel` (each variable's WEB code syntax holds the USS name).

| Collection | Modes | Variables |
|---|---|---|
| `Theme` | `standard`, `colourblind`, `high-contrast` | `color/surface/{base,panel,raised}`, `color/border`, `color/text/{primary,secondary,disabled}`, `color/accent`, `color/on-accent`, `color/readout`, `color/{success,warning,danger}`, `color/player/1`–`8` |
| `Scale` | `value` | `space/{1,2,3,4,6,8,12}` (4 px base), `font-size/{12,14,16,20,28}`, `radius/{sm,md,lg}` |

The palette is option G ("less industrial": steel panels, cyan actions, gold readouts), chosen by the owner on 2026-10-09 after three rounds. The colourblind player colours are Okabe–Ito with grey in place of black; colourblind `danger` is a bright reddish-purple (`#F06BB8`) so it stays distinct from `warning` (orange) for every common colour-vision deficiency.
