# v0.14 UX design (Figma)

The v0.14 AI opponents UI: the lobby's Add AI button and AI rows (host and joined views), the Visibility setting with the Private (single-player) state and the refusal hint, the AI tag in the top bar, diplomacy panel, gift dialog, alerts and end screen (with each AI's difficulty and resolved style), the in-match menu's Paused state, and the `IconAi` tag icon. Same look as v0.7 to v0.13 (Jersey 10, square corners, the `Theme` and `Scale` variables, the existing `Panel`, `Button` and `Toggle` components, `Icon/px/*` icon components). The gift dialog, end screen and in-match menu were last drawn in Inter (v0.6); these frames redraw them in Jersey 10 as the game shows them. **No v0.14 UI production code is written until this file records the owner's approval.** A change to an approved frame goes back through Figma first.

Element names for the UXML: lobby `add-ai-button` and `add-ai-hint` under `player-rows`; each AI row is an `ai-row` with `ai-tag` (an `IconAi` image and a label), `ai-difficulty` and `ai-style` dropdowns (host) or labels (others), the existing team control, and `ai-remove`; `visibility-row` (segmented, like `size-options`) and `visibility-hint` as the first option group in the match settings; `invite-button` hidden and `lobby-subtitle` reworded when Private. In match: an `ai-tag` element after the name in the top bar's `players`, `diplomacy-rows`, `gift-targets`, the alert row and the end screen's player cell (one shared builder, e.g. `PlayerNameLabel`, so every place is the same). Menu: `match-menu-paused` (the banner) and `match-menu-note` (the line whose text changes). `IconKind` gains `Ai`, and `PixelIcons` the matching `IconAi` bitmap (below).

## Decisions for the owner

1. **The AI tag** is `IconAi` (16 px) right after the callsign, then "AI · <difficulty>" in the secondary colour: "Cmdr. Vasquez [icon] AI · Hard". The icon stands in for the spec's first "·". The alternative is text only ("Cmdr. Vasquez · AI · Hard") with no icon.
2. **The full tag everywhere**, difficulty included, as the spec says: top bar, diplomacy, gift dialog, alerts and end screen. Alerts get longer ("Cmdr. Vasquez [icon] AI · Hard shares vision with you"); the alternative is "AI" without the difficulty in alerts only.
3. **Host AI row on one line:** swatch, callsign, tag ("AI" only: the Difficulty dropdown beside it shows the level), Difficulty, Style, Team, Ready, ×. To fit, the lobby's Players and Match settings panels widen from 520 to 560 px (the map preview moves 40 px right).
4. **Add AI defaults:** Normal, Random style, the first unused colour, and in Teams mode the team with the fewest players. The button is a Secondary button under the list with a one-line hint; it hides when the lobby has 8 seats.
5. **Colour:** the host changes an AI's colour by clicking its swatch (the same colour picker as their own, taken colours crossed out). Not drawn as a separate state.
6. **Joined view:** an explicitly chosen style is shown ("Turtle"); a Random style shows "Random". Only the end screen reveals what Random became.
7. **Visibility** is the first match setting, a segmented row like Map size, Friends selected by default, with a one-line hint that describes the selected value. Private's hint is in the warning colour.
8. **Private hides the join line:** the subtitle's LAN / internet address (the lobby's "Direct" information) is replaced by "You are hosting a private match · single-player: nobody can join"; Invite friends is hidden. The footer status reads "Single-player: start when you like".
9. **Refusal:** clicking Private with another human connected changes nothing and shows "Remove the other players first" under the row (warning colour) until the selection or the player list changes. AIs never block Private.
10. **Lobby height:** with Visibility added, panel spacing tightens from 24 to 16 px so four players, Add AI and all settings fit 1080 px; longer player lists scroll in the left column.
11. **Paused menu:** title "Menu · Paused", a warning-bordered banner "Paused · You're the only player" above the buttons, and the bottom note changes to "The match is paused while this is open. Resume (or Esc) continues it." Opening Settings from the menu keeps the pause. With two or more humans the menu is today's, unchanged.
12. **End screen:** the AI's difficulty and style follow the tag; a style that was Random shows its result with "(random)" ("Turtle (random)"). The Player column widens from 200 to 400 px.
13. **Gift dialog:** AIs are listed as gift targets like anyone, with the tag.
14. **Replays** (spec §2.3 lists them) use the same tag in the replay viewer's player list; no separate frame.
