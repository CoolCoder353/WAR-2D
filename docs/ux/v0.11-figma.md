# v0.11 UX design (Figma)

The private start points' UI: the host's two new lobby settings, a map preview without start markers, and the *PlacingHQ* overlay with numbered option rings, the pick timer and the teammates' options. Same look as v0.8 to v0.10 (Jersey 10, square corners, token names unchanged, the existing `Button` component). A change to an approved frame goes back through Figma first.

- **File:** [WAR-2D v0.6 UX](https://www.figma.com/design/JrMColnJiQbFfODqyPjBYf), page **v0.11 New Ground** (node 57:493)
- **Status:** **Approved** by the owner on 2026-10-17, and built.

Element names for the UXML: `start-options-row`, `start-options-hint`, `pick-time-row`, `pick-time-hint`, `hq-prompt-title` (with the timer), `hq-option-buttons`, `hq-progress`; the rings and edge badges are drawn in the world/overlay (`ClearingRing`, an edge-badge element per off-screen option).

## Decisions for the owner

1. **Option buttons** in the prompt move the camera between options (no new key). Edge badges are also clickable and do the same.
2. **Disabled, not hidden:** values that don't fit stay visible but disabled, with one hint line naming the site count.
3. **Pick time 0 (Random)** has no frame of its own: the HQs are placed as the scene loads and the existing countdown overlay shows at once.
4. **Joined players** see the two settings as they see the others today (the host's values, read-only); no separate frame.
5. **Teammates' options** are dashed in the teammate's colour, a teammate's pick solid; enemies' options are never drawn (nobody has them).
6. The HQ is 5×5 (the old prompt said 3×3).

## Approval record

Approved by the owner on 2026-10-17 ("Figma looks good, do it"), decisions 1 to 6 as written. Built as:

- **Lobby:** `Lobby.uxml` `start-options-row`, `start-options-hint`, `pick-time-row`, `pick-time-hint`, bound in `LobbyController.ShowStartSettings` (the fit check is `LobbyRules.FitsMap`, the same one the server runs at Start; Start match is also disabled while the options don't fit).
- **HQ prompt:** `Hud.uxml` `hq-prompt-title`, `hq-prompt-body`, `hq-option-buttons`, `hq-progress`, from `HudOverlayController` (`PlacementPrompt`, built by `HudController.ShowStartOptions`). Once the local HQ is placed, the rule line and the option buttons hide and the progress line stays.
- **Badges:** `StartMarkersController` (layer `start-markers`): a badge on each ring on screen, an edge badge with an arrow (a `Painter2D` triangle: Jersey 10 has no arrow glyphs) for each one off screen; badges click to move the camera. At the default zoom a ring can be larger than the screen, so its badge is kept inside the view, and edge badges stay below the top bar.
- **Rings:** `ClearingRing.Set(..., solid)`; a teammate's pick is solid (`BuildingPlacement.ShowOwnClearing`).
