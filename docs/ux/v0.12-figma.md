# v0.12 UX design (Figma)

The v0.12 Arsenal HUD: the producers' type selector and single queue row, the Builder's build row with the three producers, the Detonate order, the unit icons in the selection panel, the Detonate key binding, and 13 new pixel icons. Same look as v0.7 to v0.11 (Jersey 10, square corners, the `Theme` and `Scale` variables, the existing `Panel`, `Command button` and `Button` components). **No v0.12 UI production code is written until this file records the owner's approval.** A change to an approved frame goes back through Figma first.

- **File:** [WAR-2D v0.6 UX](https://www.figma.com/design/JrMColnJiQbFfODqyPjBYf), page **v0.12 Arsenal** (node 63:2)
- **Status:** **Approved** by the owner on 2026-10-17, after three icon rounds. Not built yet.

## Decisions for the owner

1. **Icons.** The 13 drafts above. Units are drawn side-on, with the accent colours yellow (Builder, Digger, Artillery, Flamethrower, factories), slate (Tank and Heavy wheels), blue (Scout and Sniper lenses) and red (bomber's fuse, Detonate, Barracks flag). As in v0.7, rejected icons get a round of three options each.
2. **Barracks icon.** A new hut-and-flag icon instead of keeping the Spawner's factory icon, so it can't be mistaken for the Heavy Factory.
3. **Switching type:** one click, **no confirm**. The tooltip warns when a queue would be cleared. The alternative is an inline confirm like Demolish when the queue isn't empty.
4. **The HQ uses the same layout**, with its single type shown as a selected button, so the queue row is in the same place on every producer.
5. **Several producers of the same kind on different types:** every type in use is Active, the info line lists them ("Mixed: Scout (1), Tank (2)"), − and + change every queue, and picking a type sets them all and clears their queues.
6. **Producers of different kinds** selected together: no selector and no queue row, a one-line hint, and the rally point still works.
7. **Build row order:** Miner, Barracks, Heavy Factory, Siege Workshop, Wall, Bomb, Radar, in one row (the card widens from 440 to 452 px). The proposed costs **Heavy Factory 400** and **Siege Workshop 250** are new numbers for `GameConfig.xml` (the spec gives none); Barracks keeps the Spawner's 200.
8. **Detonate** shows whenever the selection holds a suicide bomber, key **B** (owner, 2026-10-17); only the bombers explode. Its hint warns that the blast hits your own units and buildings.
9. **Tooltip contents** for a type: cost, build time, and a short role line (for example "Range 14, splash 2, can't fire closer than 4").
10. **Selection panel:** the unit icon fills each chip's icon slot, and chips show display names with spaces ("Suicide bomber").

## Approval record

- **2026-10-17, owner:** "I don't like the builder or artillery icons, the rest is approved." Approved as drawn: the command card states, the selection panel and Controls frames, decisions 1 to 10, and 11 of the 13 icons (Tank, Digger, Scout, Heavy, Sniper, Flamethrower, Suicide bomber, Detonate, Barracks, Heavy Factory, Siege Workshop).
- **Icons, round 2 (2026-10-17):** from `Icon options – v0.12` (67:2489) the owner chose **Artillery C (self-propelled gun)** and rejected all three Builder options.
- **Icons, round 3 (2026-10-17):** the owner chose **Builder E (bulldozer)**. The approved Builder and Artillery bitmaps replace the drafts in the `Icon/px/Builder` and `Icon/px/Artillery` components, so the Icons frame and the command card show them.
- **Approved version:** the owner names it `v0.12 approved` in Figma's version history (the plugin API can't save named versions). UI production code may start then.
