# v0.10 UX design (Figma)

The replay screens: a Replays entry on the main menu, the Replays list, the replay viewer HUD, the end screen's replay progress, and a Save replays setting. Same look as v0.8/v0.9 (square corners, token names unchanged, existing `Button` and `Toggle` components). A change to an approved frame goes back through Figma first.

- **File:** [WAR-2D v0.6 UX](https://www.figma.com/design/JrMColnJiQbFfODqyPjBYf), page **v0.10 Insight** (node 53:364)
- **Status:** **Approved** (2026-10-16). Built as drawn.

## Decisions for the owner

1. Replays sits on the main menu (not under Play), between Play and Settings.
2. List rows show the first player's colour only; the names are in the summary line.
3. Delete asks for confirmation (a small confirm dialog in the existing style, not drawn).
4. The viewer has no fog toggle or per-player view: it always shows everything (as recorded).
5. Save replays lives in the Graphics tab (Settings has no General tab).

## Approval record

Approved by the owner on 2026-10-16 with no changes to the five decisions above.
