# v0.16 Clarity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v0.16 Clarity: target lines, fights on the minimap, a clear HQ-placement minimap, formations, Builders that build and repair nearby on their own, and menu presentation (motion and the new lobby layout).

**Architecture:** The reading-the-battle items are client-only and built from what the client already receives, with one exception (Task 2: a unit's wall shot is sent to the shooter's owner only). Formations add a slot offset and a group speed to each ordered unit, carried on the `Unit` component and copied into SoA arrays the movement stage reads. Auto-work runs at the tick boundary in `SimCommandSystem`, giving idle Builders the same Build or Repair order a click would. Menus change only UXML, USS and the controllers' class toggles.

**Tech Stack:** Unity 6000.4.1f1, C#, Unity Entities (DOTS) and Burst for the sim, Mirror, UI Toolkit (UXML/USS), NUnit EditMode and PlayMode tests run through the live editor.

**Spec:** [docs/superpowers/specs/2026-11-01-v0.16-clarity-design.md](../specs/2026-11-01-v0.16-clarity-design.md). **Figma:** [docs/ux/v0.16-figma.md](../../ux/v0.16-figma.md) (approved 2026-11-01; strategic zoom dropped).

## Global Constraints

- **Branch:** `release/v0.16`, created from `polish/presentation` (it holds the 2026-11-01 work `main` doesn't have yet). Never commit on `main`. **No co-author or AI attribution in commit messages** (CLAUDE.md).
- **Tests:** compile with `tools/unity-compile.sh` while working; run a task's own tests with `tools/unity-test.sh EditMode <filter>` (or `PlayMode <filter>`); **both full suites (`tools/unity-test.sh EditMode` and `tools/unity-test.sh PlayMode`) pass before every commit.** Known timing-sensitive tests: `HudTests.GiftToEnemyMovesResources`, `PerformanceTests.MinimapRedrawAtTenThousandOwnUnitsIsUnderOneMillisecond` (known-issues); re-run a failure alone before treating it as real.
- **Server authority:** every `[Command]` calls `CommandGate.Allow(sender, nameof(...))` first and validates arguments; main-thread code never touches `Unit` entities or `SimData` arrays between ticks (use `SimCommand`s); new tick work never completes its own jobs.
- **Clients only see what their team sees:** nothing new reaches a client except Task 2's owner-only wall target; `LeakTests` keep passing and gain a test for it.
- **Config:** every new number goes in `Assets/Resources/GameConfig.xml`, parsed strictly by `ConfigParser`; the test fixture `ConfigParserTests.ValidXml` gains the same blocks.
- **Logging:** `WarLog` with a category, never `Debug.Log`. **Style:** XML `/// <summary>` on public members, PascalCase, match the surrounding code.
- **Version:** `GameVersion.Protocol` 16, `bundleVersion` 0.16.0 (Task 2).
- **UI:** build only what the approved Figma frames show (T, C, P, G, M1, M2). No strategic zoom.
- **Spec corrections this plan makes** (recorded in the spec in Task 11): unit wall shots reach their owner as an attack event (the spec said nothing new is sent); the minimap pulses come from health drops the client already gets, because attack events are only sent for attackers inside the client's camera box.

```csharp
namespace WAR2D.Net.Replication
{
    /// <summary>
    /// How an attack event names its target: a unit or building id (positive), unnamed (0), or, only in the attacker
    /// owner's own events (v0.16), a wall tile as <c>-(tile index + 1)</c>.
    /// </summary>
    public static class AttackTargets
    {
        /// <summary>The target id for a wall tile (row-major index).</summary>
        public static int OfWall(int tileIndex) => -(tileIndex + 1);

        /// <summary>True when the target names a wall tile.</summary>
        public static bool IsWall(int targetId) => targetId < 0;

        /// <summary>The wall tile a negative target names.</summary>
        public static int WallTile(int targetId) => -targetId - 1;
    }
}
```

`TargetLineRules.cs`:

```csharp
using System.Collections.Generic;
using Unity.Mathematics;
using WAR2D.Net.Replication;

namespace WAR2D.Client.Overlays
{
    /// <summary>What a target line points at: a unit or building (red) or a wall (orange).</summary>
    public enum TargetLineKind : byte { Attack, Wall }

    /// <summary>
    /// The pure rules behind target lines (v0.16, Figma T): each attacker's last named target and when it fired, how long a
    /// line holds after the last shot, which kind it is, and which lines survive the cap. No Unity objects.
    /// </summary>
    public sealed class TargetLineRules
    {
        private readonly Dictionary<int, (int target, float at)> last = new Dictionary<int, (int, float)>();
        private readonly List<int> stale = new List<int>();
        private readonly float hold;

        /// <summary>Most lines drawn at once.</summary>
        public int Max { get; }

        public TargetLineRules(float holdSeconds, int max) { hold = holdSeconds; Max = max; }

        /// <summary>An attack event: <paramref name="attackerId"/> fired at <paramref name="targetId"/> (0 when unnamed).</summary>
        public void Shot(int attackerId, int targetId, float now)
        {
            if (targetId == 0) return;
            last[attackerId] = (targetId, now);
        }

        /// <summary>The attacker's target while its line holds.</summary>
        public bool TryTarget(int attackerId, float now, out int targetId)
        {
            targetId = 0;
            if (!last.TryGetValue(attackerId, out var shot) || now - shot.at > hold) return false;
            targetId = shot.target;
            return true;
        }

        /// <summary>Drops attackers whose lines expired (call once a frame).</summary>
        public void Forget(float now)
        {
            stale.Clear();
            foreach (var pair in last) if (now - pair.Value.at > hold) stale.Add(pair.Key);
            foreach (int id in stale) last.Remove(id);
        }

        /// <summary>Red for units and buildings, orange for walls.</summary>
        public static TargetLineKind KindOf(int targetId) => AttackTargets.IsWall(targetId) ? TargetLineKind.Wall : TargetLineKind.Attack;

        /// <summary>The ids of the <paramref name="max"/> attackers nearest <paramref name="centre"/>, nearest first.</summary>
        public static List<int> Nearest(List<(int id, float2 at)> from, float2 centre, int max)
        {
            from.Sort((a, b) => math.distancesq(a.at, centre).CompareTo(math.distancesq(b.at, centre)));
            var kept = new List<int>(math.min(max, from.Count));
            for (int i = 0; i < from.Count && i < max; i++) kept.Add(from[i].id);
            return kept;
        }
    }
}
```

`MinimapCombat.cs`:

```csharp
using System.Collections.Generic;
using Unity.Mathematics;

namespace WAR2D.Client
{
    /// <summary>
    /// Fights on the minimap (v0.16, Figma C): a known unit or building whose health drops reports a hit; hits are binned into
    /// cells, each cell pulses once for <c>PulseSeconds</c> and then stays quiet for <c>QuietSeconds</c>. A pulse is "own"
    /// (the alert colour) when any of its hits was on the local player's things. Built only from health the client already
    /// gets for every unit and building it knows, so it shows nothing it couldn't already see.
    /// </summary>
    public sealed class MinimapCombat
    {
        /// <summary>One pulse: where, whether the player's own things were hit, and when it started.</summary>
        public struct Pulse { public int2 Cell; public float2 Centre; public bool Own; public float Start; }

        /// <summary>The local client's pulses (replaced when a match starts).</summary>
        public static MinimapCombat Current { get; set; }

        private readonly int cellTiles, max;
        private readonly float pulseSeconds, quietSeconds;
        private readonly List<Pulse> pulses = new List<Pulse>();
        private readonly Dictionary<int2, float> quietUntil = new Dictionary<int2, float>();

        /// <summary>Pulses showing now.</summary>
        public IReadOnlyList<Pulse> Pulses => pulses;

        /// <summary>Seconds a pulse lasts.</summary>
        public float PulseSeconds => pulseSeconds;

        public MinimapCombat(int cellTiles, float pulseSeconds, float quietSeconds, int max)
        {
            this.cellTiles = cellTiles; this.pulseSeconds = pulseSeconds; this.quietSeconds = quietSeconds; this.max = max;
        }

        /// <summary>A hit at <paramref name="position"/>; <paramref name="own"/> when the thing hit is the local player's.</summary>
        public void Hit(float2 position, bool own, float now)
        {
            int2 cell = (int2)math.floor(position / cellTiles);
            for (int i = 0; i < pulses.Count; i++)
            {
                if (!pulses[i].Cell.Equals(cell)) continue;
                if (own && !pulses[i].Own) { Pulse p = pulses[i]; p.Own = true; pulses[i] = p; }
                return;
            }
            if (quietUntil.TryGetValue(cell, out float until) && now < until) return;
            if (pulses.Count >= max) return;
            pulses.Add(new Pulse { Cell = cell, Centre = ((float2)cell + 0.5f) * cellTiles, Own = own, Start = now });
            quietUntil[cell] = now + pulseSeconds + quietSeconds;
        }

        /// <summary>Drops finished pulses.</summary>
        public void Update(float now) => pulses.RemoveAll(p => now - p.Start >= pulseSeconds);
    }
}
```

`FormationRules.cs`:

```csharp
using System.Collections.Generic;
using Unity.Mathematics;

namespace WAR2D.Sim
{
    /// <summary>
    /// Formation slots (v0.16): a block centred on the goal, facing from the group's centre towards the goal, rows of about
    /// √(2n) (wider than deep), the front row for Heavies, Tanks, Flamethrowers and bombers, the back for Snipers and
    /// Artillery, the rest between. Within a row, units take slots in the order of where they stand across the facing, so
    /// paths don't cross. Pure.
    /// </summary>
    public static class FormationRules
    {
        /// <summary>0 front, 1 middle, 2 back.</summary>
        public static int RoleOf(UnitType type) => type switch
        {
            UnitType.Heavy or UnitType.Tank or UnitType.Flamethrower or UnitType.SuicideBomber => 0,
            UnitType.Sniper or UnitType.Artillery => 2,
            _ => 1,
        };

        /// <summary>Fills <paramref name="offsets"/> (one per unit, same order) with each unit's slot relative to the goal.</summary>
        public static void Layout(IReadOnlyList<UnitType> types, IReadOnlyList<float2> positions, float2 goal, float spacing, List<float2> offsets)
        {
            int n = types.Count;
            offsets.Clear();
            for (int i = 0; i < n; i++) offsets.Add(float2.zero);
            if (n == 0) return;
            float2 centroid = 0;
            for (int i = 0; i < n; i++) centroid += positions[i];
            centroid /= n;
            float2 facing = math.normalizesafe(goal - centroid, new float2(0, 1));
            float2 across = new float2(facing.y, -facing.x);
            int cols = math.max(1, (int)math.ceil(math.sqrt(2f * n)));
            int rows = (n + cols - 1) / cols;

            var order = new List<int>(n);
            for (int i = 0; i < n; i++) order.Add(i);
            order.Sort((a, b) => RoleOf(types[a]) != RoleOf(types[b]) ? RoleOf(types[a]).CompareTo(RoleOf(types[b])) : a.CompareTo(b));

            var row = new List<int>(cols);
            for (int r = 0; r < rows; r++)
            {
                row.Clear();
                for (int k = r * cols; k < math.min(n, (r + 1) * cols); k++) row.Add(order[k]);
                row.Sort((a, b) => math.dot(positions[a], across).CompareTo(math.dot(positions[b], across)));
                float depth = ((rows - 1) * 0.5f - r) * spacing; // row 0 is the front
                for (int c = 0; c < row.Count; c++)
                {
                    float side = (c - (row.Count - 1) * 0.5f) * spacing;
                    offsets[row[c]] = facing * depth + across * side;
                }
            }
        }
    }
}
```

```csharp
private readonly List<UnitType> formationTypes = new List<UnitType>();
private readonly List<float2> formationPositions = new List<float2>();
private readonly List<float2> formationOffsets = new List<float2>();
private float formationSpeed;

/// <summary>
/// Lays the movers of a formation order into a block at the goal (<see cref="FormationRules"/>), moving slots on rock
/// or a footprint in towards the goal until they are on open floor, and records the slowest member's speed. Two or
/// more movers only.
/// </summary>
private void AssignFormation(SimData data, SimContext context, int2 goal)
{
    formationSlots.Clear(); formationTypes.Clear(); formationPositions.Clear();
    foreach (List<int> list in moversByClass) formationSlots.AddRange(list);
    if (formationSlots.Count < 2) { formationSlots.Clear(); return; }
    formationSpeed = float.MaxValue;
    foreach (int s in formationSlots)
    {
        formationTypes.Add((UnitType)data.Type[s]);
        formationPositions.Add(data.Positions[s]);
        formationSpeed = math.min(formationSpeed, data.SpeedByType[data.Type[s]]);
    }
    FormationRules.Layout(formationTypes, formationPositions, (float2)goal + 0.5f, data.FormationSpacing, formationOffsets);
    for (int k = 0; k < formationOffsets.Count; k++)
    {
        float2 offset = formationOffsets[k];
        for (int tries = 0; tries < 4 && !context.Map.IsWalkable((int2)math.floor((float2)goal + 0.5f + offset)); tries++) offset *= 0.5f;
        formationOffsets[k] = context.Map.IsWalkable((int2)math.floor((float2)goal + 0.5f + offset)) ? offset : float2.zero;
    }
}

/// <summary>Gives each formation mover's pending order its slot and the group speed.</summary>
private void ApplyFormationPending(SimData data)
{
    for (int k = 0; k < formationSlots.Count; k++)
    {
        int id = data.IdOf[formationSlots[k]];
        if (!data.PendingOrders.TryGetValue(id, out PendingOrder order)) continue;
        order.Offset = formationOffsets[k];
        order.GroupSpeed = formationSpeed;
        data.PendingOrders[id] = order;
    }
    formationSlots.Clear();
}
```

```csharp
using Unity.Mathematics;

namespace WAR2D.Sim
{
    public partial class SimCommandSystem
    {
        /// <summary>
        /// Idle Builders work on their own (v0.16): each Builder with no order, no work, no queued waypoints and nothing
        /// pending looks, once every <see cref="SimData.AutoWorkSlice"/> ticks, for its owner's nearest blueprint or wall
        /// blueprint within <see cref="SimData.AutoWorkRadius"/> tiles, then for the nearest own building or wall below
        /// <see cref="SimData.AutoWorkRepairBelow"/> of its health (not while the owner has no money), and takes it as a
        /// Build or Repair order, exactly as a click would (<see cref="ApplyWorkOrder"/>). Never a teammate's.
        /// </summary>
        private void AutoWork(SimData data, SimContext context, int unitCount, int tick)
        {
            float r = data.AutoWorkRadius, rSq = r * r;
            for (int slot = 0; slot < unitCount; slot++)
            {
                if (data.Type[slot] != (byte)UnitType.Builder || data.Health[slot] <= 0f) continue;
                int id = data.IdOf[slot];
                if ((tick + NetIdAllocator.IndexOf(id)) % data.AutoWorkSlice != 0) continue;
                if (data.WorkKind[slot] != WorkKinds.None || data.Stance[slot] != Stances.Idle || HasLiveOrder(data, slot, id)) continue;
                if (data.PendingOrders.ContainsKey(id) || context.Waypoints.CountOf(id) > 0) continue;
                int owner = data.OwnerId[slot];
                float2 at = data.Positions[slot];
                if (TryNearestBuildWork(data, context, owner, at, rSq, out int2 tile)
                    || (context.BudgetOf == null || context.BudgetOf(owner) > 0f) && TryNearestRepair(data, context, owner, at, rSq, out tile))
                {
                    OrderKind kind = IsRepairTarget(data, context, tile) ? OrderKind.Repair : OrderKind.Build;
                    ApplyWorkOrder(data, context, new SimCommand { Kind = SimCommandKind.OrderUnits, Order = kind, OwnerId = owner, Tile = tile, Ids = new[] { id } }, unitCount);
                }
            }
        }

        /// <summary>The nearest own blueprint (its anchor) or wall blueprint within reach.</summary>
        private static bool TryNearestBuildWork(SimData data, SimContext context, int owner, float2 at, float rSq, out int2 tile)
        {
            tile = default;
            float best = rSq;
            int count = data.BuildingCount[0];
            for (int b = 0; b < count; b++)
            {
                if (data.BuildingOwnerId[b] != owner || (data.BuildingFlag[b] & global::BuildingFlags.UnderConstruction) == 0 || data.BuildingHealth[b] <= 0f) continue;
                float d = DistanceSqToRect(at, data.BuildingAnchor[b], data.BuildingSize[b]);
                if (d < best) { best = d; tile = data.BuildingAnchor[b]; }
            }
            int ownerSlot = context.SlotOf(owner);
            ScanWalls(data, at, rSq, (index, d) => data.WallState[index] == WallStates.Blueprint && data.WallOwnerSlot[index] == ownerSlot, ref best, ref tile);
            return best < rSq;
        }

        /// <summary>The nearest own finished building or built wall under the repair share, within reach.</summary>
        private static bool TryNearestRepair(SimData data, SimContext context, int owner, float2 at, float rSq, out int2 tile)
        {
            tile = default;
            float best = rSq;
            int count = data.BuildingCount[0];
            for (int b = 0; b < count; b++)
            {
                if (data.BuildingOwnerId[b] != owner || (data.BuildingFlag[b] & global::BuildingFlags.UnderConstruction) != 0) continue;
                float h = data.BuildingHealth[b], max = data.BuildingMaxHealth[b];
                if (h <= 0f || h >= max * data.AutoWorkRepairBelow) continue;
                float d = DistanceSqToRect(at, data.BuildingAnchor[b], data.BuildingSize[b]);
                if (d < best) { best = d; tile = data.BuildingAnchor[b]; }
            }
            int ownerSlot = context.SlotOf(owner);
            ScanWalls(data, at, rSq, (index, d) => data.WallState[index] == WallStates.Built && data.WallOwnerSlot[index] == ownerSlot
                && data.WallHealth[index] < data.WallMaxHealth * data.AutoWorkRepairBelow, ref best, ref tile);
            return best < rSq;
        }

        /// <summary>True when the tile is a finished building or a built wall (a Repair), not a blueprint (a Build).</summary>
        private static bool IsRepairTarget(SimData data, SimContext context, int2 tile)
        {
            int index = context.Map.Grid.Index(tile);
            if (data.WallState[index] != WallStates.None) return data.WallState[index] == WallStates.Built;
            if (!context.BuildingAt.TryGetValue(index, out int buildingId)) return false;
            int b = data.BuildingSlotOfIndex[NetIdAllocator.IndexOf(buildingId)];
            return (data.BuildingFlag[b] & global::BuildingFlags.UnderConstruction) == 0;
        }

        private static void ScanWalls(SimData data, float2 at, float rSq, System.Func<int, float, bool> wanted, ref float best, ref int2 tile)
        {
            int r = (int)math.ceil(math.sqrt(rSq));
            int2 c = (int2)math.floor(at);
            for (int y = math.max(0, c.y - r); y <= math.min(data.Height - 1, c.y + r); y++)
            for (int x = math.max(0, c.x - r); x <= math.min(data.Width - 1, c.x + r); x++)
            {
                float d = math.distancesq(at, new float2(x + 0.5f, y + 0.5f));
                int index = y * data.Width + x;
                if (d < best && wanted(index, d)) { best = d; tile = new int2(x, y); }
            }
        }

        private static float DistanceSqToRect(float2 p, int2 anchor, int2 size)
        {
            float2 lo = anchor, hi = anchor + size;
            float2 d = math.max(math.max(lo - p, p - hi), 0f);
            return math.lengthsq(d);
        }
    }
}
```
