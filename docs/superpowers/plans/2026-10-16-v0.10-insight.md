**Goal:** A localhost control API and `tools/war2d` CLI that Claude and the owner can drive a running game with, debug overlays, structured logs (`WarLog`), and fog-free match recordings that every player receives after the match and watches from a Replays screen.

**Architecture:** Everything dev-only lives under `Assets/Scripts/Dev/` and is gated by `DevUi.Enabled` (editor or development build) plus `-debugApi` in builds. The API is a TCP JSON-lines server whose socket threads only queue lines; a dispatcher runs every command on the main thread and reaches the world only through existing server paths and `SimCommand`s. Recordings reuse the replication stack: a virtual spectator client (`SimData.SeesAll`) feeds a GZip file writer; playback feeds the same payloads into `ClientWorld`, `ClientBuildings` and `ClientTerrain` offline, like `MenuBattle`.

**Tech Stack:** Unity `6000.4.1f1`, Entities + Burst, Mirror (KCP and FizzySteamworks), Newtonsoft JSON (`com.unity.nuget.newtonsoft-json` 3.2.2, already installed), `System.IO.Compression` (GZip), UI Toolkit, NUnit EditMode/PlayMode through the live editor, Python 3 (standard library) for the CLI.

**Spec:** [2026-10-16-v0.10-insight-design.md](../specs/2026-10-16-v0.10-insight-design.md). Parent: [roadmap](../../roadmap.md) §2 v0.10.

## Global Constraints

- The control API is open only when `DevUi.Enabled` **and** (`Application.isEditor` **or** `-debugApi` on the command line). Release builds never open it. It binds **127.0.0.1** only; default port **7790**; every request carries the token from `<persistentDataPath>/debugapi/<port>.json`.
- API handlers run on the **main thread**. They never touch `Unit` entities or `SimData` arrays between ticks; they queue `SimCommand`s or call existing server methods, and read the last settled data (captured in a `SimContext.Settled` handler) or client stores.
- Every new `[Command]` has `requiresAuthority = false`, a `NetworkConnectionToClient sender = null` parameter, calls `CommandGate.Allow(sender, nameof(...))` first (with a budget entry in `CommandGate`), and validates its arguments server-side.
- Nothing about a recording is sent to any client before `GameCore.CurrentState == GameState.GameOver`. `LeakTests` must keep passing and gain the recorder cases.
- Recording header never contains Steam IDs.
- All new numbers go in `Assets/Resources/GameConfig.xml` (`<Replays>`), parsed strictly by `ConfigParser`.
- Any HUD or menu change goes through Figma and the owner's approval first (Task 15 is the gate for Tasks 17).
- Logging: new code uses `WarLog`; Burst jobs never log.
- Perf budget: host main-thread tick ≤ 25 ms p95 at 80,000 units with the recorder on (`tools/perf-run.sh`).

```csharp
using System;
using System.IO;
using System.Linq;

namespace WAR2D.Dev.Logging
{
    /// <summary>One session's log file: <c>war2d-&lt;UTC time&gt;-&lt;pid&gt;.log</c>, keeping the newest <c>keep</c> files in its folder.</summary>
    public sealed class LogFile : IDisposable
    {
        private readonly StreamWriter writer;
        private readonly object gate = new object();

        /// <summary>The path of the file opened last (tests and the API's <c>info</c>).</summary>
        public static string LastPath { get; private set; }

        private LogFile(string path)
        {
            writer = new StreamWriter(new FileStream(path, FileMode.Create, FileAccess.Write, FileShare.Read)) { AutoFlush = true };
            LastPath = path;
        }

        /// <summary>Opens a new file in <paramref name="directory"/> and deletes the oldest beyond <paramref name="keep"/>.</summary>
        public static LogFile Open(string directory, int keep = 10)
        {
            Directory.CreateDirectory(directory);
            string name = $"war2d-{DateTime.UtcNow:yyyyMMdd-HHmmss}-{System.Diagnostics.Process.GetCurrentProcess().Id}.log";
            var file = new LogFile(Path.Combine(directory, name));
            foreach (string old in Directory.GetFiles(directory, "war2d-*.log").OrderByDescending(p => p, StringComparer.Ordinal).Skip(keep))
            {
                try { File.Delete(old); } catch (IOException) { } // another process may hold it
            }
            return file;
        }

        /// <summary>Formats and appends one entry (thread-safe).</summary>
        public void Write(in LogEntry e)
        {
            string line = $"{e.Utc:HH:mm:ss.fff} f{e.Frame} t{e.Tick} {e.Level,-5} [{e.Category}] {e.Message}";
            lock (gate) writer.WriteLine(line);
        }

        public void Dispose()
        {
            lock (gate) writer.Dispose();
        }
    }
}
```

- [ ] **Step 4: Implement `WarLog`**

```csharp
using System;
using System.Collections.Generic;
using System.Threading;
using UnityEngine;

namespace WAR2D.Dev.Logging
{
    public enum LogCategory : byte { Sim, Net, Replication, Steam, Lobby, Match, UI, Audio, Art, Replay, Dev, Unity }
    public enum LogLevel : byte { Debug, Info, Warn, Error }

    /// <summary>One log line.</summary>
    public struct LogEntry
    {
        public long Seq;
        public DateTime Utc;
        public int Frame;
        /// <summary>The sim tick when it was written, or -1.</summary>
        public int Tick;
        public LogCategory Category;
        public LogLevel Level;
        public string Message;
    }

    /// <summary>
    /// The game's structured log: a category and level per entry, an in-memory ring (the developer console and
    /// the debug API read it), a per-session file, and Unity's own log. Unity and Mirror messages are captured
    /// into <see cref="LogCategory.Unity"/>. Thread-safe; never call it from Burst jobs.
    /// </summary>
    public static class WarLog
    {
        private static readonly object Gate = new object();
        private static LogEntry[] ring = new LogEntry[8192];
        private static int head, count;
        private static long seq;
        private static readonly LogLevel[] Levels = NewLevels();
        private static LogFile file;
        [ThreadStatic] private static bool forwarding;

        /// <summary>Supplies the sim tick for new entries (set by the server's sim; null gives -1).</summary>
        public static Func<int> TickSource;

        /// <summary>False in tests: entries stay out of Unity's log (and so out of the test runner's log assertions).</summary>
        internal static bool ForwardToUnity = true;

        /// <summary>The newest entry's sequence number (0 when empty).</summary>
        public static long LastSeq { get { lock (Gate) return seq; } }

        public static void Debug(LogCategory c, string message) => Write(c, LogLevel.Debug, message);
        public static void Info(LogCategory c, string message) => Write(c, LogLevel.Info, message);
        public static void Warn(LogCategory c, string message) => Write(c, LogLevel.Warn, message);
        public static void Error(LogCategory c, string message) => Write(c, LogLevel.Error, message);

        public static LogLevel LevelOf(LogCategory c) => Levels[(int)c];

        /// <summary>Entries below <paramref name="level"/> in category <paramref name="c"/> are dropped.</summary>
        public static void SetLevel(LogCategory c, LogLevel level) => Levels[(int)c] = level;

        public static void Write(LogCategory c, LogLevel level, string message)
        {
            if (level < Levels[(int)c]) return;
            int tick = -1;
            try { tick = TickSource?.Invoke() ?? -1; } catch { }
            LogEntry e;
            lock (Gate)
            {
                e = new LogEntry
                {
                    Seq = ++seq, Utc = DateTime.UtcNow, Frame = MainThreadFrame, Tick = tick,
                    Category = c, Level = level, Message = message ?? "",
                };
                ring[(head + count) % ring.Length] = e;
                if (count < ring.Length) count++;
                else head = (head + 1) % ring.Length;
            }
            file?.Write(e);
            if (!ForwardToUnity || c == LogCategory.Unity) return;
            forwarding = true;
            try
            {
                string text = $"[{c}] {message}";
                if (level == LogLevel.Error) UnityEngine.Debug.LogError(text);
                else if (level == LogLevel.Warn) UnityEngine.Debug.LogWarning(text);
                else UnityEngine.Debug.Log(text);
            }
            finally { forwarding = false; }
        }

        /// <summary>The newest entries (oldest first), filtered.</summary>
        public static List<LogEntry> Tail(int max, LogCategory? category = null, LogLevel min = LogLevel.Debug, long afterSeq = 0)
        {
            var result = new List<LogEntry>();
            lock (Gate)
            {
                for (int i = count - 1; i >= 0 && result.Count < max; i--)
                {
                    LogEntry e = ring[(head + i) % ring.Length];
                    if (e.Seq <= afterSeq) break;
                    if (category.HasValue && e.Category != category.Value) continue;
                    if (e.Level < min) continue;
                    result.Add(e);
                }
            }
            result.Reverse();
            return result;
        }

        private static int mainThreadId = -1;

        /// <summary>The frame on the main thread; -1 from other threads (Time.frameCount is main-thread only).</summary>
        private static int MainThreadFrame => Thread.CurrentThread.ManagedThreadId == mainThreadId ? Time.frameCount : -1;

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        private static void Boot()
        {
            mainThreadId = Thread.CurrentThread.ManagedThreadId;
            Application.logMessageReceivedThreaded -= Capture;
            Application.logMessageReceivedThreaded += Capture;
            if (!(Application.isEditor && Application.isBatchMode))
            {
                file?.Dispose();
                file = LogFile.Open(System.IO.Path.Combine(Application.persistentDataPath, "logs"));
            }
            Application.quitting -= Close;
            Application.quitting += Close;
        }

        private static void Close() { file?.Dispose(); file = null; }

        /// <summary>Unity's and Mirror's own messages, into the Unity category (skipping WarLog's own forwarding).</summary>
        private static void Capture(string condition, string stackTrace, LogType type)
        {
            if (forwarding) return;
            LogLevel level = type == LogType.Log ? LogLevel.Info : type == LogType.Warning ? LogLevel.Warn : LogLevel.Error;
            Write(LogCategory.Unity, level, level == LogLevel.Error && !string.IsNullOrEmpty(stackTrace) ? condition + "\n" + stackTrace : condition);
        }

        internal static void ResetForTests(int capacity = 8192)
        {
            lock (Gate) { ring = new LogEntry[capacity]; head = 0; count = 0; seq = 0; }
            Array.Copy(NewLevels(), Levels, Levels.Length);
            TickSource = null;
        }

        private static LogLevel[] NewLevels()
        {
            var levels = new LogLevel[Enum.GetValues(typeof(LogCategory)).Length];
            for (int i = 0; i < levels.Length; i++) levels[i] = LogLevel.Info;
            return levels;
        }
    }
}
```

```csharp
namespace WAR2D.Sim
{
    /// <summary>
    /// Dev-only pause for the tick (the debug API's <c>pause</c>, <c>resume</c> and <c>step</c>). While paused the
    /// boundary still settles the previous tick but the tick doesn't run, unless a step is pending.
    /// </summary>
    public sealed class SimPause
    {
        /// <summary>True to stop the tick.</summary>
        public bool Paused;

        /// <summary>Ticks still allowed to run while paused.</summary>
        public int StepBudget { get; private set; }

        /// <summary>Lets <paramref name="ticks"/> more ticks run while paused.</summary>
        public void Step(int ticks) => StepBudget += System.Math.Max(0, ticks);

        /// <summary>Called once per boundary: true when this tick may run (consuming a step when paused).</summary>
        public bool TryRun()
        {
            if (!Paused) return true;
            if (StepBudget <= 0) return false;
            StepBudget--;
            return true;
        }

        /// <summary>True while paused with no step pending: the building systems skip their frame too.</summary>
        public bool Frozen => Paused && StepBudget <= 0;
    }
}
```

```csharp
using System;
using Newtonsoft.Json.Linq;
using Unity.Mathematics;

namespace WAR2D.Dev.DebugApi
{
    /// <summary>Typed reads of a request's <c>args</c>; a missing or mistyped value throws <see cref="DebugError"/>.</summary>
    public static class DebugArgs
    {
        public static bool Has(JObject a, string name) => a != null && a[name] != null && a[name].Type != JTokenType.Null;

        public static int Int(JObject a, string name, int? fallback = null)
        {
            if (!Has(a, name)) return fallback ?? throw new DebugError($"missing '{name}'");
            if (a[name].Type != JTokenType.Integer) throw new DebugError($"'{name}' must be a whole number");
            return (int)a[name];
        }

        public static float Float(JObject a, string name, float? fallback = null)
        {
            if (!Has(a, name)) return fallback ?? throw new DebugError($"missing '{name}'");
            if (a[name].Type != JTokenType.Integer && a[name].Type != JTokenType.Float) throw new DebugError($"'{name}' must be a number");
            float v = (float)a[name];
            if (float.IsNaN(v) || float.IsInfinity(v)) throw new DebugError($"'{name}' must be finite");
            return v;
        }

        public static string Str(JObject a, string name, string fallback = null)
        {
            if (!Has(a, name)) return fallback ?? throw new DebugError($"missing '{name}'");
            return (string)a[name];
        }

        public static bool Bool(JObject a, string name, bool? fallback = null)
        {
            if (!Has(a, name)) return fallback ?? throw new DebugError($"missing '{name}'");
            if (a[name].Type != JTokenType.Boolean) throw new DebugError($"'{name}' must be true or false");
            return (bool)a[name];
        }

        public static int2 Int2(JObject a, string name)
        {
            if (!(a?[name] is JArray arr) || arr.Count != 2) throw new DebugError($"'{name}' must be [x, y]");
            return new int2((int)arr[0], (int)arr[1]);
        }

        /// <summary>A box as [x0, y0, x1, y1] (inclusive tiles, any corner order).</summary>
        public static (int2 min, int2 max) Box(JObject a, string name)
        {
            if (!(a?[name] is JArray arr) || arr.Count != 4) throw new DebugError($"'{name}' must be [x0, y0, x1, y1]");
            int2 p = new int2((int)arr[0], (int)arr[1]), q = new int2((int)arr[2], (int)arr[3]);
            return (math.min(p, q), math.max(p, q));
        }

        public static T Enum<T>(JObject a, string name, T? fallback = null) where T : struct
        {
            if (!Has(a, name)) return fallback ?? throw new DebugError($"missing '{name}'");
            if (System.Enum.TryParse((string)a[name], true, out T v) && System.Enum.IsDefined(typeof(T), v)) return v;
            throw new DebugError($"'{name}' must be one of {string.Join(", ", System.Enum.GetNames(typeof(T)))}");
        }
    }
```

```csharp
// DebugDispatcher.cs
using System;
using System.Collections.Generic;
using Newtonsoft.Json;
using Newtonsoft.Json.Linq;
using WAR2D.Dev.Logging;

namespace WAR2D.Dev.DebugApi
{
    /// <summary>
    /// Runs API requests on the main thread: parses a JSON line, checks the token and the command's role, calls
    /// its handler and replies with <c>{id, ok, result}</c> or <c>{id, ok: false, error}</c>. A handler that
    /// returns a <see cref="DebugWait"/> is polled by <see cref="Pump"/> until it answers or times out.
    /// </summary>
    public sealed class DebugDispatcher
    {
        private sealed class Pending { public long Id; public DebugWait Wait; public float Elapsed; public Action<string> Reply; }

        private readonly DebugRegistry registry;
        private readonly string token;
        private readonly Func<bool> isServer, isClient;
        private readonly List<Pending> pending = new List<Pending>();
        private static readonly JsonSerializerSettings Settings = new JsonSerializerSettings { ReferenceLoopHandling = ReferenceLoopHandling.Ignore };

        public DebugDispatcher(DebugRegistry registry, string token, Func<bool> isServer, Func<bool> isClient)
        {
            this.registry = registry;
            this.token = token;
            this.isServer = isServer;
            this.isClient = isClient;
        }

        public void Handle(string line, Action<string> reply)
        {
            long id = 0;
            try
            {
                JObject request = JObject.Parse(line);
                id = request["id"]?.Type == JTokenType.Integer ? (long)request["id"] : 0;
                if ((string)request["token"] != token) throw new DebugError("bad or missing token");
                string name = (string)request["cmd"];
                if (!registry.TryGet(name, out DebugRegistry.Entry entry)) throw new DebugError($"unknown command '{name}' (try 'help')");
                if (entry.Role == DebugRole.Server && !isServer()) throw new DebugError($"'{name}' needs the server (host) process");
                if (entry.Role == DebugRole.Client && !isClient()) throw new DebugError($"'{name}' needs a client");
                object result;
                using (DevApi.Scope()) result = entry.Handler(request["args"] as JObject ?? new JObject());
                if (result is DebugWait wait) pending.Add(new Pending { Id = id, Wait = wait, Reply = reply });
                else reply(Ok(id, result));
            }
            catch (DebugError e) { reply(Fail(id, e.Message)); }
            catch (JsonException e) { reply(Fail(id, "bad JSON: " + e.Message)); }
            catch (Exception e)
            {
                WarLog.Error(LogCategory.Dev, $"debug API command failed: {e}");
                reply(Fail(id, e.GetType().Name + ": " + e.Message));
            }
        }

        /// <summary>Polls pending waits (call once a frame).</summary>
        public void Pump(float deltaSeconds)
        {
            for (int i = pending.Count - 1; i >= 0; i--)
            {
                Pending p = pending[i];
                p.Elapsed += deltaSeconds;
                object result;
                try { result = p.Wait.Poll(); }
                catch (Exception e) { pending.RemoveAt(i); p.Reply(Fail(p.Id, e.Message)); continue; }
                if (result != null) { pending.RemoveAt(i); p.Reply(Ok(p.Id, result)); }
                else if (p.Elapsed >= p.Wait.TimeoutSeconds) { pending.RemoveAt(i); p.Reply(Fail(p.Id, $"timed out after {p.Wait.TimeoutSeconds:0.#} s")); }
            }
        }

        private static string Ok(long id, object result) =>
            JsonConvert.SerializeObject(new { id, ok = true, result }, Formatting.None, Settings);

        private static string Fail(long id, string error) =>
            JsonConvert.SerializeObject(new { id, ok = false, error }, Formatting.None, Settings);
    }
}
```

```csharp
using System.IO;
using System.Net;
using System.Net.Sockets;
using System.Text;
using System.Threading;
using Mirror;
using UnityEngine;
using WAR2D.Dev.Logging;

namespace WAR2D.Dev.DebugApi
{
    /// <summary>
    /// The control API's socket: a 127.0.0.1 TCP listener whose threads only read and write lines. Requests are
    /// queued and run by <see cref="DebugDispatcher"/> on the main thread in <see cref="Update"/>.
    /// </summary>
    public sealed class DebugServer : MonoBehaviour
    {
        public static DebugServer Instance { get; private set; }

        /// <summary>The command table (shared with the developer console's <c>dev</c> command).</summary>
        public static DebugRegistry Registry { get; } = CreateRegistry();

        public int BoundPort { get; private set; }

        private TcpListener listener;
        private Thread acceptThread;
        private volatile bool stopping;
        private DebugDispatcher dispatcher;
        private readonly ConcurrentQueue<(string line, Action<string> reply)> inbox = new ConcurrentQueue<(string, Action<string>)>();
        private string apiFile;

        private static DebugRegistry CreateRegistry()
        {
            var r = new DebugRegistry();
            DebugCommands.RegisterAll(r);
            return r;
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
        private static void Boot()
        {
            if (DebugApi.Allowed) EnsureRunning();
        }

        /// <summary>Starts the server if it isn't running (no-op when the API isn't allowed).</summary>
        public static void EnsureRunning()
        {
            if (Instance != null || !DebugApi.Allowed) return;
            var go = new GameObject("DebugServer");
            DontDestroyOnLoad(go);
            go.AddComponent<DebugServer>();
        }

        /// <summary>Stops the server (tests).</summary>
        public static void Shutdown()
        {
            if (Instance != null) DestroyImmediate(Instance.gameObject);
        }

        private void Awake()
        {
            Instance = this;
            dispatcher = new DebugDispatcher(Registry, DebugApi.Token, () => NetworkServer.active, () => NetworkClient.active);
            try
            {
                listener = new TcpListener(IPAddress.Loopback, DebugApi.Port);
                listener.Start();
            }
            catch (SocketException e)
            {
                WarLog.Error(LogCategory.Dev, $"debug API could not listen on 127.0.0.1:{DebugApi.Port}: {e.Message}");
                Destroy(gameObject);
                return;
            }
            BoundPort = ((IPEndPoint)listener.LocalEndpoint).Port;
            WriteApiFile();
            acceptThread = new Thread(AcceptLoop) { IsBackground = true, Name = "DebugApi accept" };
            acceptThread.Start();
            DebugApi.Listening = true;
            WarLog.Info(LogCategory.Dev, $"debug API listening on 127.0.0.1:{BoundPort}");
        }

        private void WriteApiFile()
        {
            string dir = Path.Combine(Application.persistentDataPath, "debugapi");
            Directory.CreateDirectory(dir);
            apiFile = Path.Combine(dir, BoundPort + ".json");
            string role = Application.isEditor ? "editor" : "player";
            File.WriteAllText(apiFile, $"{{\"port\":{BoundPort},\"pid\":{System.Diagnostics.Process.GetCurrentProcess().Id},\"token\":\"{DebugApi.Token}\",\"role\":\"{role}\"}}");
        }

        private void AcceptLoop()
        {
            while (!stopping)
            {
                TcpClient client;
                try { client = listener.AcceptTcpClient(); }
                catch (SocketException) { return; }
                catch (ObjectDisposedException) { return; }
                new Thread(() => Serve(client)) { IsBackground = true, Name = "DebugApi client" }.Start();
            }
        }

        private void Serve(TcpClient client)
        {
            using (client)
            {
                NetworkStream stream = client.GetStream();
                var reader = new StreamReader(stream, Encoding.UTF8);
                var writer = new StreamWriter(stream, new UTF8Encoding(false)) { AutoFlush = true };
                var gate = new object();
                void Reply(string text) { lock (gate) { try { writer.WriteLine(text); } catch (IOException) { } catch (ObjectDisposedException) { } } }
                try
                {
                    string line;
                    while (!stopping && (line = reader.ReadLine()) != null)
                        if (line.Length > 0 && line.Length <= 1 << 20) inbox.Enqueue((line, Reply));
                }
                catch (IOException) { }
                catch (ObjectDisposedException) { }
            }
        }

        private void Update()
        {
            int budget = 64; // requests per frame
            while (budget-- > 0 && inbox.TryDequeue(out var item)) dispatcher.Handle(item.line, item.reply);
            dispatcher.Pump(Time.unscaledDeltaTime);
        }

        private void OnDestroy()
        {
            stopping = true;
            try { listener?.Stop(); } catch (SocketException) { }
            if (apiFile != null && File.Exists(apiFile)) File.Delete(apiFile);
            if (Instance == this) { Instance = null; DebugApi.Listening = false; }
        }
    }
}
```

Note: replies written from the main thread go through the per-connection `Reply` closure; the socket thread only reads.

```csharp
using Unity.Mathematics;
using WAR2D.Sim;

namespace WAR2D.Dev.DebugApi
{
    /// <summary>
    /// A managed copy of the settled unit SoA, taken in <see cref="SimContext.Settled"/> (main thread, jobs complete),
    /// so API commands and overlays can read units between ticks without touching <see cref="SimData"/>.
    /// Captured only while someone wants it.
    /// </summary>
    public sealed class SettledSnapshot
    {
        public static SettledSnapshot Current { get; private set; }

        /// <summary>Readers that need captures (the API while listening counts as one).</summary>
        public static int Wanted;

        public int Tick, Count;
        public int[] Id = new int[0], Owner = new int[0], Target = new int[0], OrderSlot = new int[0];
        public byte[] Type = new byte[0], Stance = new byte[0], TargetKind = new byte[0];
        public float2[] Position = new float2[0];
        public float[] Health = new float[0], MaxHealth = new float[0];

        public static void Attach(SimContext sim)
        {
            Current = new SettledSnapshot();
            sim.Settled += OnSettled;
        }

        public static void Detach(SimContext sim)
        {
            sim.Settled -= OnSettled;
            Current = null;
        }

        private static void OnSettled(SimData data, int tick, int count)
        {
            if (Current != null && (DebugApi.Listening || Wanted > 0)) Current.Capture(data, tick, count);
        }

        public void Capture(SimData data, int tick, int count)
        {
            Tick = tick;
            Count = count;
            if (Id.Length < count)
            {
                int n = math.max(count, Id.Length * 2);
                Id = new int[n]; Owner = new int[n]; Target = new int[n]; OrderSlot = new int[n];
                Type = new byte[n]; Stance = new byte[n]; TargetKind = new byte[n];
                Position = new float2[n]; Health = new float[n]; MaxHealth = new float[n];
            }
            for (int i = 0; i < count; i++)
            {
                Id[i] = data.IdOf[i];
                Owner[i] = data.OwnerId[i];
                Type[i] = data.Type[i];
                Stance[i] = data.Stance[i];
                Position[i] = data.Positions[i];
                Health[i] = data.Health[i];
                MaxHealth[i] = data.MaxHealth[i];
                Target[i] = data.Target[i];
                TargetKind[i] = data.TargetKind[i];
                OrderSlot[i] = data.OrderSlot[i];
            }
        }
    }
}
```

```csharp
            for (int y = max.y; y >= min.y; y -= cell)

                    bool explored = data.Explored[grid * data.FogCells + c] != 0;
                    sb.Append(visible ? '#' : explored ? '+' : ' ');
                }
                sb.Append('\n');
            }
```

```csharp
/// <summary>Kills the named units (dev tools), like <see cref="KillUnits"/> for an owner.</summary>
private void KillIds(SimData data, SimContext context, int[] ids)
{
    if (ids == null || ids.Length == 0) return;
    var wanted = new System.Collections.Generic.HashSet<int>(ids);
    using NativeArray<Entity> entities = unitQuery.ToEntityArray(Allocator.Temp);
    using NativeArray<Unit> units = unitQuery.ToComponentDataArray<Unit>(Allocator.Temp);
    var doomed = new NativeList<Entity>(ids.Length, Allocator.Temp);
    for (int i = 0; i < units.Length; i++)
    {
        if (!wanted.Contains(units[i].Id)) continue;
        doomed.Add(entities[i]);
        context.Ids.Free(units[i].Id);
        if (units[i].OwnerSlot < data.UnitsBySlot.Length) data.UnitsBySlot[units[i].OwnerSlot]--;
        context.RaiseUnitDied(units[i].Id, units[i].Position);
    }
    EntityManager.DestroyEntity(doomed.AsArray());
    doomed.Dispose();
}
```

```python
#!/usr/bin/env python3
"""WAR-2D control API client. See [docs/debugging.md](../../debugging.md)."""
import argparse, glob, json, os, socket, subprocess, sys, time

def api_dirs():
    home = os.path.expanduser("~")
    # Unity's persistentDataPath on Linux: ~/.config/unity3d/<company>/<product>
    return glob.glob(os.path.join(home, ".config", "unity3d", "*", "*", "debugapi"))

def instances():
    found = []
    for d in api_dirs():
        for f in glob.glob(os.path.join(d, "*.json")):
            try:
                info = json.load(open(f))
                os.kill(info["pid"], 0)  # still running?
                found.append(info)
            except (OSError, ValueError, KeyError):
                pass
    return sorted(found, key=lambda i: i["port"])

def parse_value(text):
    try:
        return json.loads(text)
    except ValueError:
        return text

def parse_args(pairs):
    args = {}
    for p in pairs:
        if "=" not in p:
            raise SystemExit(f"argument '{p}' must be key=value")
        k, v = p.split("=", 1)
        args[k] = parse_value(v)
    return args

class Client:
    def __init__(self, port):
        info = next((i for i in instances() if i["port"] == port), None)
        if info is None:
            raise SystemExit(f"no WAR-2D debug API on port {port} (run 'war2d list')")
        self.token = info["token"]
        self.sock = socket.create_connection(("127.0.0.1", port), timeout=600)
        self.file = self.sock.makefile("rw", encoding="utf-8", newline="\n")
        self.next_id = 1

    def call(self, cmd, args):
        rid = self.next_id; self.next_id += 1
        self.file.write(json.dumps({"id": rid, "token": self.token, "cmd": cmd, "args": args}) + "\n")
        self.file.flush()
        while True:
            line = self.file.readline()
            if not line:
                raise SystemExit("connection closed")
            reply = json.loads(line)
            if reply.get("id") == rid:
                return reply

def show(reply, raw):
    if raw or not reply.get("ok"):
        print(json.dumps(reply, indent=None if raw else 2))
        return 0 if reply.get("ok") else 1
    result = reply["result"]
    if isinstance(result, str):
        print(result)
    elif isinstance(result, dict) and isinstance(result.get("units"), list):
        print(f"count {result['count']}" + (f" (tick {result['tick']})" if "tick" in result else ""))
        for u in result["units"]:
            if u: print(f"  {u['id']:>9} owner {u['owner']:>7} {u['type']:<8} at {u['pos'][0]:7.2f},{u['pos'][1]:7.2f} hp {u['health']}")
    else:
        print(json.dumps(result, indent=2))
    return 0

def launch(clients):
    exe = os.path.join(os.path.dirname(__file__), "..", "Builds", "Dev", "WAR-2D.x86_64")
    if not os.path.exists(exe):
        raise SystemExit("build it first: WAR-2D > Build > Linux (Dev)")
    logs = os.path.join(os.path.dirname(exe), "logs"); os.makedirs(logs, exist_ok=True)
    procs = []
    for i in range(clients + 1):
        port = 7790 + i
        log = os.path.join(logs, f"{'host' if i == 0 else 'client%d' % i}.log")
        procs.append(subprocess.Popen([exe, "-debugApi", str(port), "-direct", "-noSteam", "-screen-width", "960", "-screen-height", "540", "-screen-fullscreen", "0", "-logFile", log]))
    deadline = time.time() + 60
    while time.time() < deadline and len({i["port"] for i in instances()} & set(range(7790, 7791 + clients))) < clients + 1:
        time.sleep(0.5)
    for p, i in zip(procs, range(clients + 1)):
        print(f"{'host' if i == 0 else 'client%d' % i}: pid {p.pid}, port {7790 + i}")
    return 0

def selftest():
    assert parse_args(["tile=[1,2]", "type=Tank", "on=true", "n=3"]) == {"tile": [1, 2], "type": "Tank", "on": True, "n": 3}
    print("ok")
    return 0

def main():
    ap = argparse.ArgumentParser(prog="war2d", description="Drive a running WAR-2D (editor play mode or a dev build with -debugApi).")
    ap.add_argument("--port", type=int, default=7790)
    ap.add_argument("--json", action="store_true", help="print the raw reply")
    ap.add_argument("command")
    ap.add_argument("args", nargs="*", help="key=value (values are JSON when they parse)")
    ap.add_argument("--clients", type=int, default=1, help="launch: joining clients")
    o = ap.parse_args()
    if o.command == "list":
        for i in instances(): print(f"port {i['port']}  pid {i['pid']}  {i['role']}")
        return 0
    if o.command == "launch": return launch(o.clients)
    if o.command == "selftest": return selftest()
    client = Client(o.port)
```

```csharp
// OverlayLayers.cs
using System.Collections.Generic;
using Newtonsoft.Json.Linq;
using Unity.Mathematics;
using UnityEngine;
using WAR2D.Net.Replication;
using WAR2D.Sim;

namespace WAR2D.Dev.Overlays
{
    /// <summary>What one layer draws: an optional grid texture (a texel per tile or fog cell) and lines in world space.</summary>
    public sealed class OverlayCanvas
    {
        public int GridWidth, GridHeight;
        public float CellSize = 1f;
        public Color32[] Texels;
        public readonly List<(float2 a, float2 b, Color32 c)> Lines = new List<(float2, float2, Color32)>();

        public void Grid(int width, int height, float cellSize)
        {
            if (Texels == null || Texels.Length != width * height) Texels = new Color32[width * height];
            else System.Array.Clear(Texels, 0, Texels.Length);
            GridWidth = width; GridHeight = height; CellSize = cellSize;
        }

        public void Line(float2 a, float2 b, Color32 c) => Lines.Add((a, b, c));

        public void Clear() { Lines.Clear(); if (Texels != null) System.Array.Clear(Texels, 0, Texels.Length); }
    }

    /// <summary>One debug overlay. Server layers copy what they need in <see cref="OnSettled"/>; <see cref="Draw"/> runs on the main thread.</summary>
    public abstract class OverlayLayer
    {
        public abstract string Name { get; }
        /// <summary>True when the layer reads server data (only the host process can draw it).</summary>
        public virtual bool ServerOnly => true;
        public abstract KeyCode Hotkey { get; }
        /// <summary>The <c>overlay</c> command's extra arguments (e.g. <c>owner</c>).</summary>
        public JObject Args = new JObject();
        public virtual void OnSettled(SimData data, int tick, int count) { }
        public abstract void Draw(OverlayCanvas canvas);
    }

    /// <summary>Tiles under building footprints (<c>MapGrid.Used</c>).</summary>
    public sealed class FootprintsLayer : OverlayLayer
    {
        public override string Name => "Footprints";
        public override KeyCode Hotkey => KeyCode.F7;
        private byte[] used = new byte[0];
        private int w, h;

        public override void OnSettled(SimData data, int tick, int count)
        {
            w = data.Width; h = data.Height;
            if (used.Length != w * h) used = new byte[w * h];
            data.Used.CopyTo(used);
        }

        public override void Draw(OverlayCanvas c)
        {
            c.Grid(w, h, 1f);
            for (int i = 0; i < used.Length; i++) if (used[i] != 0) c.Texels[i] = new Color32(255, 160, 0, 110);
        }
    }

    /// <summary>One owner's fog grid: visible bright, explored dim. Server: <c>owner</c> argument; client: its own fog.</summary>
    public sealed class FogLayer : OverlayLayer
    {
        public override string Name => "Fog";
        public override bool ServerOnly => false;
        public override KeyCode Hotkey => KeyCode.F4;
        private byte[] visible = new byte[0], explored = new byte[0];
        private int fw, fh, cell = 2;

        public override void OnSettled(SimData data, int tick, int count)
        {
            int owner = Args?["owner"]?.Type == JTokenType.Integer ? (int)Args["owner"] : 0;
            int grid = SimContext.Current != null ? SimContext.Current.VisionOf(owner) : (owner == SimHarnessOwnerForTests ? 0 : -1);
            if (grid < 0) return;
            fw = data.FogW; fh = data.FogH; cell = data.FogCellSize;
            int n = data.FogCells;
            if (visible.Length != n) { visible = new byte[n]; explored = new byte[n]; }
            for (int i = 0; i < n; i++) { visible[i] = data.Visible[grid * n + i]; explored[i] = data.Explored[grid * n + i]; }
        }

        /// <summary>Unused outside tests: lets EditMode tests pick grid 0 without a live context.</summary>
        internal static int SimHarnessOwnerForTests = int.MinValue;

        public override void Draw(OverlayCanvas c)
        {
            if (!Mirror.NetworkServer.active && ClientFog.Current?.State != null) // a client: its own fog
            {
                ClientFog fog = ClientFog.Current;
                c.Grid(fog.Width, fog.Height, fog.CellSize);
                for (int i = 0; i < fog.State.Length; i++)
                    c.Texels[i] = fog.State[i] == (byte)FogState.Visible ? new Color32(0, 255, 120, 70) : fog.State[i] == (byte)FogState.Explored ? new Color32(0, 120, 255, 50) : default;
                return;
            }
            c.Grid(fw, fh, cell);
            for (int i = 0; i < visible.Length; i++)
                c.Texels[i] = visible[i] != 0 ? new Color32(0, 255, 120, 70) : explored[i] != 0 ? new Color32(0, 120, 255, 50) : default;
        }
    }

    /// <summary>Units per spatial-hash cell as a heat map.</summary>
    public sealed class HashLayer : OverlayLayer
    {
        public override string Name => "Hash";
        public override KeyCode Hotkey => KeyCode.F6;
        private int[] counts = new int[0];
        private int hw, hh, size;

        public override void OnSettled(SimData data, int tick, int count)
        {
            size = data.HashCellSize;
            hw = (data.Width + size - 1) / size; hh = (data.Height + size - 1) / size;
            if (counts.Length != hw * hh) counts = new int[hw * hh];
            System.Array.Clear(counts, 0, counts.Length);
            for (int i = 0; i < count; i++)
            {
                float2 p = data.Positions[i];
                int x = math.clamp((int)(p.x / size), 0, hw - 1), y = math.clamp((int)(p.y / size), 0, hh - 1);
                counts[y * hw + x]++;
            }
        }

        public override void Draw(OverlayCanvas c)
        {
            c.Grid(hw, hh, size);
            for (int i = 0; i < counts.Length; i++)
            {
                if (counts[i] == 0) continue;
                float t = math.saturate(math.log2(counts[i] + 1) / 8f);
                c.Texels[i] = (Color32)Color.Lerp(new Color(0f, 0.4f, 1f, 0.35f), new Color(1f, 0f, 0f, 0.6f), t);
            }
        }
    }
```

```csharp
// DebugOverlays.cs
using System.Collections.Generic;
using System.Linq;
using Mirror;
using Newtonsoft.Json.Linq;
using Unity.Mathematics;
using UnityEngine;
using UnityEngine.InputSystem;
using WAR2D.Client.Render;
using WAR2D.Dev.DebugApi;
using WAR2D.Sim;

namespace WAR2D.Dev.Overlays
{
    /// <summary>
    /// Development-build overlays over the map: one point-filtered sprite per grid layer and one line mesh. Server
    /// layers draw only in the host process. Toggled from the API (<c>overlay</c>), the console, or F1–F9.
    /// With every layer off it does nothing.
    /// </summary>
    public sealed class DebugOverlays : MonoBehaviour
    {
        public static DebugOverlays Instance { get; private set; }

        private readonly List<OverlayLayer> layers = new List<OverlayLayer>
        {
            new FootprintsLayer(), new FogLayer(), new HashLayer(),
            // Task 11 adds: FlowLayer, RoutesLayer, TargetsLayer, SectorsLayer, InterestLayer, TerrainLayer
        };
        private readonly HashSet<OverlayLayer> on = new HashSet<OverlayLayer>();
        private readonly Dictionary<OverlayLayer, (SpriteRenderer sprite, Texture2D texture, OverlayCanvas canvas)> views = new Dictionary<OverlayLayer, (SpriteRenderer, Texture2D, OverlayCanvas)>();
        private Mesh lineMesh;
        private Material lineMaterial;
        private SimContext attached;

        public IEnumerable<string> Enabled => on.Select(l => l.Name);

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
        private static void Boot()
        {
            if (!DevUi.Enabled) return;
            var go = new GameObject("DebugOverlays");
            DontDestroyOnLoad(go);
            Instance = go.AddComponent<DebugOverlays>();
            ViewCommands.OverlayHook = (name, enable, args) => Instance.Set(name, enable, args);
        }

        public object Set(string name, bool enable, JObject args)
        {
            OverlayLayer layer = layers.FirstOrDefault(l => string.Equals(l.Name, name, System.StringComparison.OrdinalIgnoreCase))
                                 ?? throw new DebugError($"no layer '{name}' (layers: {string.Join(", ", layers.Select(l => l.Name))})");
            if (enable && layer.ServerOnly && !NetworkServer.active) throw new DebugError($"'{layer.Name}' reads server data: use the host process");
            if (args != null) layer.Args = args;
            if (enable && on.Add(layer)) SettledSnapshot.Wanted++;
            if (!enable && on.Remove(layer)) { SettledSnapshot.Wanted--; Hide(layer); }
            return Enabled.ToArray();
        }

        private void Update()
        {
            Keyboard k = Keyboard.current;
            if (k != null)
                foreach (OverlayLayer l in layers)
                    if (KeyFor(l.Hotkey) is Key key && k[key].wasPressedThisFrame)
                        try { Set(l.Name, !on.Contains(l), null); } catch (DebugError e) { Logging.WarLog.Warn(Logging.LogCategory.Dev, e.Message); }

            if (on.Count == 0) { Detach(); return; }
            if (SimContext.Current != attached) { Detach(); attached = SimContext.Current; if (attached != null) attached.Settled += Capture; }
        }

        private void Capture(SimData data, int tick, int count)
        {
            foreach (OverlayLayer l in on) l.OnSettled(data, tick, count);
        }

        private void Detach()
        {
            if (attached != null) attached.Settled -= Capture;
            attached = null;
        }

        private void LateUpdate()
        {
            if (on.Count == 0) return;
            var lines = new List<(float2, float2, Color32)>();
            foreach (OverlayLayer l in on)
            {
                if (!views.TryGetValue(l, out var view)) view = views[l] = (NewSprite(l.Name), null, new OverlayCanvas());
                view.canvas.Lines.Clear();
                l.Draw(view.canvas);
                lines.AddRange(view.canvas.Lines);
                if (view.canvas.Texels == null || view.canvas.GridWidth == 0) { view.sprite.enabled = false; continue; }
                if (view.texture == null || view.texture.width != view.canvas.GridWidth || view.texture.height != view.canvas.GridHeight)
                {
                    view.texture = new Texture2D(view.canvas.GridWidth, view.canvas.GridHeight, TextureFormat.RGBA32, false) { filterMode = FilterMode.Point, wrapMode = TextureWrapMode.Clamp };
                    view.sprite.sprite = Sprite.Create(view.texture, new Rect(0, 0, view.texture.width, view.texture.height), Vector2.zero, 1f / view.canvas.CellSize);
                    views[l] = view;
                }
                view.texture.SetPixels32(view.canvas.Texels);
                view.texture.Apply(false);
                view.sprite.enabled = true;
            }
            DrawLines(lines);
        }

        private SpriteRenderer NewSprite(string name)
        {
            var go = new GameObject("Overlay " + name);
            go.transform.SetParent(transform, false);
            var sr = go.AddComponent<SpriteRenderer>();
            sr.sortingOrder = SortingOrders.DebugOverlay;
            return sr;
        }

        private void Hide(OverlayLayer l)
        {
            if (views.TryGetValue(l, out var v) && v.sprite != null) v.sprite.enabled = false;
        }

        private void DrawLines(List<(float2 a, float2 b, Color32 c)> lines)
        {
            if (lines.Count == 0) return;
            if (lineMesh == null) { lineMesh = new Mesh { indexFormat = UnityEngine.Rendering.IndexFormat.UInt32 }; lineMaterial = new Material(Shader.Find("Universal Render Pipeline/2D/Sprite-Unlit-Default")); }
            var v = new Vector3[lines.Count * 2];
            var c = new Color32[lines.Count * 2];
            var idx = new int[lines.Count * 2];
            for (int i = 0; i < lines.Count; i++)
            {
                v[2 * i] = new Vector3(lines[i].a.x, lines[i].a.y, 0f); v[2 * i + 1] = new Vector3(lines[i].b.x, lines[i].b.y, 0f);
                c[2 * i] = c[2 * i + 1] = lines[i].c; idx[2 * i] = 2 * i; idx[2 * i + 1] = 2 * i + 1;
            }
            lineMesh.Clear();
            lineMesh.vertices = v; lineMesh.colors32 = c; lineMesh.SetIndices(idx, MeshTopology.Lines, 0);
            Graphics.RenderMesh(new RenderParams(lineMaterial) { layer = 0 }, lineMesh, 0, Matrix4x4.identity);
        }

        private static Key? KeyFor(KeyCode code) => code switch
        {
            KeyCode.F1 => Key.F1, KeyCode.F2 => Key.F2, KeyCode.F3 => Key.F3, KeyCode.F4 => Key.F4, KeyCode.F5 => Key.F5,
            KeyCode.F6 => Key.F6, KeyCode.F7 => Key.F7, KeyCode.F8 => Key.F8, KeyCode.F9 => Key.F9, _ => null,
        };

        private void OnDestroy() { Detach(); if (Instance == this) Instance = null; }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.IO.Compression;
using System.Text;
using Newtonsoft.Json;

namespace WAR2D.Net.Replay
{
    public enum ReplayChannel : byte { UnitsReliable = 0, UnitsUnreliable = 1, Buildings = 2, Terrain = 3, Fog = 4, Explosions = 10, Blasts = 11, Timeline = 12, End = 13 }

    public sealed class ReplayPlayerInfo { public int OwnerId; public string Nickname; public int Colour; public int Team; }

    /// <summary>A recording's header: what the viewer needs to rebuild the map and label the players. Never Steam IDs.</summary>
    public sealed class ReplayHeader
    {
        public int Format = ReplayFile.Format;
        public string GameVersion;
        public int MapSize;
        public uint Seed;
        public MatchSettings Settings;
        public List<ReplayPlayerInfo> Players = new List<ReplayPlayerInfo>();
        public double StartedUtc;
        public float TickSeconds;
    }

    /// <summary>File layout: GZip of ("W2DR", u16 format, u32 header length, header JSON, records). Record: varint tick delta, u8 channel, varint length, payload.</summary>
    public static class ReplayFile
    {
        public const int Format = 1;
        public const string Extension = ".war2drec";
        public static readonly byte[] Magic = { (byte)'W', (byte)'2', (byte)'D', (byte)'R' };
        public const int MaxRecordBytes = 4 << 20;
        public const int MaxHeaderBytes = 1 << 20;
    }

    public sealed class ReplayWriter : IDisposable
    {
        private readonly GZipStream gzip;
        private readonly BinaryWriter writer;
        private int lastTick;

        public long BytesWritten { get; private set; }

        public ReplayWriter(Stream output, ReplayHeader header, bool leaveOpen = false)
        {
            gzip = new GZipStream(output, CompressionLevel.Fastest, leaveOpen);
            writer = new BinaryWriter(gzip, Encoding.UTF8, leaveOpen: false);
            byte[] json = Encoding.UTF8.GetBytes(JsonConvert.SerializeObject(header));
            writer.Write(ReplayFile.Magic);
            writer.Write((ushort)ReplayFile.Format);
            writer.Write((uint)json.Length);
            writer.Write(json);
            BytesWritten = 10 + json.Length;
        }

        public void Write(int tick, ReplayChannel channel, ReadOnlySpan<byte> payload)
        {
            int delta = Math.Max(0, tick - lastTick);
            lastTick = Math.Max(lastTick, tick);
            // Order matters (the reader expects it): tick delta, channel, length, payload.
            int n = WriteVarint(delta);
            writer.Write((byte)channel);
            n += 1 + WriteVarint(payload.Length);
            writer.Write(payload);
            BytesWritten += n + payload.Length;
        }

        private int WriteVarint(int value)
        {
            uint v = (uint)value;
            int n = 0;
            while (v >= 0x80) { writer.Write((byte)(v | 0x80)); v >>= 7; n++; }
            writer.Write((byte)v);
            return n + 1;
        }

        public void Dispose() => writer.Dispose(); // closes the GZip stream (and the output unless leaveOpen)
    }

    public sealed class ReplayReader : IDisposable
    {
        private readonly BinaryReader reader;
        private byte[] buffer = new byte[64 * 1024];
        private int tick;

        public ReplayHeader Header { get; private set; }
        /// <summary>Why reading stopped early, or null at a clean end.</summary>
        public string Error { get; private set; }

        private ReplayReader(BinaryReader reader) { this.reader = reader; }

        public static bool TryOpen(Stream input, out ReplayReader replay, out string error)
        {
            replay = null;
            try
            {
                var r = new BinaryReader(new GZipStream(input, CompressionMode.Decompress), Encoding.UTF8);
                byte[] magic = r.ReadBytes(4);
                if (magic.Length != 4 || magic[0] != 'W' || magic[1] != '2' || magic[2] != 'D' || magic[3] != 'R') { error = "not a WAR-2D replay"; return false; }
                int format = r.ReadUInt16();
                if (format != ReplayFile.Format) { error = $"replay format {format} is not supported"; return false; }
                uint length = r.ReadUInt32();
                if (length > ReplayFile.MaxHeaderBytes) { error = "header too large"; return false; }
                byte[] json = r.ReadBytes((int)length);
                if (json.Length != length) { error = "truncated header"; return false; }
                ReplayHeader header = JsonConvert.DeserializeObject<ReplayHeader>(Encoding.UTF8.GetString(json));
                if (header == null || header.MapSize < 0 || header.TickSeconds <= 0f) { error = "bad header"; return false; }
                replay = new ReplayReader(r) { Header = header };
                error = null;
                return true;
            }
            catch (Exception e) when (e is IOException || e is InvalidDataException || e is JsonException || e is EndOfStreamException || e is ArgumentException)
            {
                error = "unreadable replay: " + e.Message;
                return false;
            }
        }

        /// <summary>The next record; false at the end or on a bad record (then <see cref="Error"/> says why). The payload is valid until the next call.</summary>
        public bool TryNext(out int recordTick, out ReplayChannel channel, out ArraySegment<byte> payload)
        {
            recordTick = 0; channel = 0; payload = default;
            if (Error != null) return false;
            try
            {
                if (!TryVarint(out int delta, allowEnd: true)) return false;
                tick += delta;
                channel = (ReplayChannel)reader.ReadByte();
                if (!TryVarint(out int length, allowEnd: false)) return false;
                if (length < 0 || length > ReplayFile.MaxRecordBytes) { Error = "record too large"; return false; }
                if (buffer.Length < length) buffer = new byte[Math.Max(length, buffer.Length * 2)];
                int read = 0;
                while (read < length) { int n = reader.Read(buffer, read, length - read); if (n <= 0) { Error = "truncated record"; return false; } read += n; }
                recordTick = tick;
                payload = new ArraySegment<byte>(buffer, 0, length);
                return true;
            }
            catch (Exception e) when (e is IOException || e is InvalidDataException || e is EndOfStreamException)
            {
                Error = "unreadable record: " + e.Message;
                return false;
            }
        }

        private bool TryVarint(out int value, bool allowEnd)
        {
            value = 0;
            int shift = 0;
            while (true)
            {
                int b = reader.BaseStream.ReadByte();
                if (b < 0) { if (!(allowEnd && shift == 0)) Error = "truncated record"; return false; }
                value |= (b & 0x7F) << shift;
                if ((b & 0x80) == 0) return true;
                shift += 7;
                if (shift > 28) { Error = "bad varint"; return false; }
            }
        }

        public void Dispose() => reader.Dispose();
    }
}
```

The writer emits each record as `varint delta`, `u8 channel`, `varint length`, payload, exactly the order the reader reads: keep the four writes in that sequence (don't fold them into one expression, whose evaluation order would put the length before the channel).

```csharp
using System;
using System.Collections.Concurrent;
using System.Collections.Generic;
using System.IO;
using System.Threading;
using Unity.Mathematics;
using WAR2D.Dev.Logging;
using WAR2D.Net.Replication;
using WAR2D.Sim;

namespace WAR2D.Net.Replay
{
    /// <summary>
    /// Records a match from the server: a virtual replication client that sees everything (bombs included, no
    /// fog, every unit on the offscreen correction tier), plus explosions, blasts, a once-a-second public
    /// timeline and the outcome. Payloads are copied on the main thread and written by a background thread;
    /// a full queue or the size cap stops the recording (the file stays playable up to there).
    /// </summary>
    public sealed class MatchRecorder : IDisposable
    {
        public const int RecorderOwner = int.MinValue + 1;
        private const int QueueLimit = 4096;

        private readonly ReplayWriter writer;
        private readonly FileStream file;
        private readonly SimContext sim;
        private readonly string partPath, finalPath;
        private readonly long maxBytes;
        private readonly BlockingCollection<(int tick, ReplayChannel channel, byte[] bytes)> queue = new BlockingCollection<(int, ReplayChannel, byte[])>(QueueLimit);
        private readonly Thread thread;
        private int currentTick;
        private long queuedBytes;
        private volatile bool stopped;

        public bool Stopped => stopped;
        public bool Finished { get; private set; }
        public string FinishedPath => Finished ? finalPath : null;

        public MatchRecorder(ReplicationService replication, SimContext sim, ReplayHeader header, string path, long maxBytes)
        {
            this.sim = sim;
            finalPath = path;
            partPath = path + ".part";
            this.maxBytes = maxBytes;
            Directory.CreateDirectory(Path.GetDirectoryName(path));
            file = new FileStream(partPath, FileMode.Create, FileAccess.Write, FileShare.Read);
            writer = new ReplayWriter(file, header);
            thread = new Thread(WriteLoop) { IsBackground = true, Name = "Replay writer" };
            thread.Start();
            replication.AddVirtualClient(RecorderOwner, Receive, seesAll: true);
            // An empty view box keeps every unit on the offscreen correction tier (spec §5.1).
            replication.SetVirtualView(RecorderOwner, new int2(int.MinValue / 2), new int2(int.MinValue / 2));
        }

        /// <summary>Call after each settled boundary with its tick, before the replication sink runs for the next.</summary>
        public void OnTick(int tick) => currentTick = tick;

        private void Receive(ArraySegment<byte> payload, int sinkChannel)
        {
            // Replication runs inside the boundary's Settled event, before any later Settled handler could call
            // OnTick, so read the tick from the clock (it advances only after Settled).
            currentTick = sim.Clock.Tick;
            ReplayChannel channel = sinkChannel switch
            {
                ReplicationService.FogSinkChannel => ReplayChannel.Fog,
                ReplicationService.BuildingSinkChannel => ReplayChannel.Buildings,
                ReplicationService.TerrainSinkChannel => ReplayChannel.Terrain,
                _ when sinkChannel == Mirror.Channels.Unreliable => ReplayChannel.UnitsUnreliable,
                _ => ReplayChannel.UnitsReliable,
            };
            Enqueue(channel, payload.AsSpan());
        }

        public void Explosions(int tick, IReadOnlyList<float2> positions) => Positions(tick, ReplayChannel.Explosions, positions);
        public void Blasts(int tick, IReadOnlyList<float2> positions) => Positions(tick, ReplayChannel.Blasts, positions);

        private void Positions(int tick, ReplayChannel channel, IReadOnlyList<float2> positions)
        {
            if (positions.Count == 0) return;
            currentTick = tick;
            var bytes = new byte[positions.Count * 8];
            for (int i = 0; i < positions.Count; i++)
            {
                BitConverter.TryWriteBytes(new Span<byte>(bytes, i * 8, 4), positions[i].x);
                BitConverter.TryWriteBytes(new Span<byte>(bytes, i * 8 + 4, 4), positions[i].y);
            }
            Enqueue(channel, bytes);
        }

        /// <summary>Once a second: each player's public numbers, for the viewer's player list.</summary>
        public void Timeline(int tick, IEnumerable<(int owner, float resources, int units, int buildings)> rows)
        {
            currentTick = tick;
            string json = Newtonsoft.Json.JsonConvert.SerializeObject(rows);
            Enqueue(ReplayChannel.Timeline, System.Text.Encoding.UTF8.GetBytes(json));
        }

        /// <summary>Writes the outcome, closes the file and renames it from <c>.part</c>.</summary>
        public void End(int tick, string outcomeJson)
        {
            if (Finished) return;
            currentTick = tick;
            bool wasStopped = stopped;
            stopped = false; // the end record always goes in
            Enqueue(ReplayChannel.End, System.Text.Encoding.UTF8.GetBytes(outcomeJson ?? "{}"));
            stopped = true;
            queue.CompleteAdding();
            thread.Join();
            writer.Dispose();
            if (File.Exists(finalPath)) File.Delete(finalPath);
            File.Move(partPath, finalPath);
            Finished = true;
            WarLog.Info(LogCategory.Replay, $"recording saved: {finalPath} ({new FileInfo(finalPath).Length / 1024} KB{(wasStopped ? ", stopped early at the size cap" : "")})");
        }

        private void Enqueue(ReplayChannel channel, ReadOnlySpan<byte> payload)
        {
            if (stopped) return;
            if (queuedBytes + payload.Length > maxBytes || !queue.TryAdd((currentTick, channel, payload.ToArray())))
            {
                stopped = true;
                WarLog.Warn(LogCategory.Replay, "recording stopped: " + (queuedBytes + payload.Length > maxBytes ? "size cap reached" : "writer fell behind"));
                return;
            }
            queuedBytes += payload.Length;
        }

        private void WriteLoop()
        {
            foreach (var (tick, channel, bytes) in queue.GetConsumingEnumerable())
            {
                try { writer.Write(tick, channel, bytes); }
                catch (IOException e) { stopped = true; WarLog.Error(LogCategory.Replay, "recording write failed: " + e.Message); }
            }
        }

        public void Dispose()
        {
            if (!Finished)
            {
                stopped = true;
                if (!queue.IsAddingCompleted) queue.CompleteAdding();
                thread.Join();
                writer.Dispose();
                if (File.Exists(partPath)) File.Delete(partPath); // an unfinished recording (the host left mid-match) is dropped
            }
            queue.Dispose();
        }
    }
}
```

The size cap counts uncompressed payload bytes (`queuedBytes`): conservative, and cheap to check on the main thread.

```csharp
    public sealed class ReplaySummary

        public string Path;
        public DateTime Utc;
        public ReplayHeader Header;
        public long Bytes;

    /// <summary>The local Replays folder (<c>persistentDataPath/Replays</c>).</summary>
    public static class ReplayLibrary
    {
        public static string Folder => System.IO.Path.Combine(Application.persistentDataPath, "Replays");

        /// <summary>Every readable replay, newest first (unreadable files are skipped, not deleted).</summary>
        public static IReadOnlyList<ReplaySummary> List()
        {
            if (!Directory.Exists(Folder)) return Array.Empty<ReplaySummary>();
            var list = new List<ReplaySummary>();
            foreach (string path in Directory.GetFiles(Folder, "*" + ReplayFile.Extension))
            {
                try
                {
                    using FileStream f = File.OpenRead(path);
                    if (!ReplayReader.TryOpen(f, out ReplayReader r, out _)) continue;
                    using (r) list.Add(new ReplaySummary { Path = path, Utc = File.GetLastWriteTimeUtc(path), Header = r.Header, Bytes = new FileInfo(path).Length });
                }
                catch (IOException) { }
            }
            return list.OrderByDescending(s => s.Utc).ToList();
        }

        public static void Delete(string path)
        {
            string full = System.IO.Path.GetFullPath(path);
            if (!full.StartsWith(System.IO.Path.GetFullPath(Folder), StringComparison.Ordinal) || !full.EndsWith(ReplayFile.Extension)) return; // only our own files
            if (File.Exists(full)) File.Delete(full);
        }

        public static void Prune(int keep)
        {
            if (!Directory.Exists(Folder)) return;
            foreach (string old in Directory.GetFiles(Folder, "*" + ReplayFile.Extension).OrderByDescending(File.GetLastWriteTimeUtc).Skip(keep))
                try { File.Delete(old); } catch (IOException) { }
        }
    }
```

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Security.Cryptography;
using Mirror;
using WAR2D.Dev.Logging;

namespace WAR2D.Net.Replay
{
    public struct ReplayOffer : NetworkMessage { public int Id; public long Bytes; public byte[] Sha256; public float DurationSeconds; }
    public struct ReplayChunk : NetworkMessage { public int Id; public long Offset; public ArraySegment<byte> Bytes; }

    public static class ReplayRules
    {
        /// <summary>Replays reveal everything, so nothing about one leaves the server before the match is over.</summary>
        public static bool MaySend(GameState state) => state == GameState.GameOver;
        public const int ChunkBytes = 16 * 1024;
    }

    /// <summary>Server side: offers the finished recording to each player and streams it to those who accept, paced per connection.</summary>
    public sealed class ReplaySender
    {
        private sealed class Transfer { public NetworkConnectionToClient Conn; public long Offset; public float Credit; }

        private readonly string path;
        private readonly int bytesPerSecond;
        private readonly ReplayOffer offer;
        private readonly Dictionary<int, Transfer> active = new Dictionary<int, Transfer>();
        private readonly HashSet<int> offered = new HashSet<int>();
        private readonly byte[] buffer = new byte[ReplayRules.ChunkBytes];
        internal Action<NetworkConnectionToClient, ReplayOffer> SendOffer = (c, m) => c.Send(m);
        internal Action<NetworkConnectionToClient, ReplayChunk> SendChunk = (c, m) => c.Send(m);

        public int Id => offer.Id;

        public ReplaySender(int id, string path, int bytesPerSecond, float durationSeconds)
        {
            this.path = path;
            this.bytesPerSecond = bytesPerSecond;
            offer = MakeOffer(id, path, durationSeconds);
        }

        public static ReplayOffer MakeOffer(int id, string path, float durationSeconds)
        {
            using FileStream f = File.OpenRead(path);
            using var sha = SHA256.Create();
            return new ReplayOffer { Id = id, Bytes = f.Length, Sha256 = sha.ComputeHash(f), DurationSeconds = durationSeconds };
        }

        /// <summary>Every chunk of a file, in order (tests and the sender).</summary>
        public static IEnumerable<ReplayChunk> Chunks(int id, string path, int chunkBytes)
        {
            byte[] all = File.ReadAllBytes(path);
            for (long o = 0; o < all.Length; o += chunkBytes)
            {
                int n = (int)Math.Min(chunkBytes, all.Length - o);
                var copy = new byte[n];
                Array.Copy(all, o, copy, 0, n);
                yield return new ReplayChunk { Id = id, Offset = o, Bytes = new ArraySegment<byte>(copy) };
            }
        }

        public void Offer(NetworkConnectionToClient conn, GameState state)
        {
            if (conn == null || !ReplayRules.MaySend(state) || !offered.Add(conn.connectionId)) return;
            SendOffer(conn, offer);
        }

        public void Accept(NetworkConnectionToClient conn, int id, GameState state)
        {
            if (conn == null || id != offer.Id || !ReplayRules.MaySend(state) || !offered.Contains(conn.connectionId)) return;
            active[conn.connectionId] = new Transfer { Conn = conn };
        }

        public void Cancel(NetworkConnectionToClient conn) { if (conn != null) active.Remove(conn.connectionId); }

        public bool Busy => active.Count > 0;

        /// <summary>Sends each accepted connection its share of <c>bytesPerSecond</c> this frame.</summary>
        public void Update(float dt, GameState state)
        {
            if (!ReplayRules.MaySend(state) || active.Count == 0) return;
            using FileStream f = File.OpenRead(path);
            var done = new List<int>();
            foreach (var pair in active)
            {
                Transfer t = pair.Value;
                if (t.Conn == null || !NetworkServer.connections.ContainsKey(pair.Key)) { done.Add(pair.Key); continue; }
                t.Credit = Math.Min(t.Credit + bytesPerSecond * dt, bytesPerSecond);
                while (t.Credit >= ReplayRules.ChunkBytes || (t.Offset + (long)t.Credit >= f.Length && t.Offset < f.Length))
                {
                    f.Position = t.Offset;
                    int n = f.Read(buffer, 0, (int)Math.Min(buffer.Length, f.Length - t.Offset));
                    if (n <= 0) break;
                    SendChunk(t.Conn, new ReplayChunk { Id = offer.Id, Offset = t.Offset, Bytes = new ArraySegment<byte>(buffer, 0, n) });
                    t.Offset += n;
                    t.Credit -= n;
                }
                if (t.Offset >= f.Length) done.Add(pair.Key);
            }
            foreach (int c in done) active.Remove(c);
        }
    }

    /// <summary>Client side: accepts an offer (when Save replays is on), writes chunks in order to a .part file, checks size and hash, then renames it.</summary>
    public sealed class ReplayReceiver
    {
        public static ReplayReceiver Current { get; private set; }

        private readonly string folder;
        private ReplayOffer offer;
        private FileStream part;
        private string partPath;
        private long next;

        public bool Active => part != null;
        public event Action<float> Progress;
        public event Action<string> Saved;

        public ReplayReceiver(string folder) { this.folder = folder; }

        /// <summary>Called from GameManager's handler: replaces <see cref="Current"/>.</summary>
        public static void Install(string folder) { Current?.Cancel(); Current = new ReplayReceiver(folder); }

        public void OnOffer(ReplayOffer o, bool accept)
        {
            Cancel();
            if (!accept || o.Bytes <= 0 || o.Bytes > (8L << 30) || o.Sha256 == null || o.Sha256.Length != 32) return;
            offer = o;
            Directory.CreateDirectory(folder);
            partPath = Path.Combine(folder, $"{DateTime.UtcNow:yyyyMMdd-HHmmss}-received{ReplayFile.Extension}.part");
            part = new FileStream(partPath, FileMode.Create, FileAccess.ReadWrite);
            next = 0;
        }

        public void OnChunk(ReplayChunk c)
        {
            if (part == null || c.Id != offer.Id) return;
            if (c.Offset != next || c.Bytes.Count == 0 || next + c.Bytes.Count > offer.Bytes) { WarLog.Warn(LogCategory.Replay, "replay transfer out of order: cancelled"); Cancel(); return; }
            part.Write(c.Bytes.Array, c.Bytes.Offset, c.Bytes.Count);
            next += c.Bytes.Count;
            Progress?.Invoke((float)next / offer.Bytes);
            if (next < offer.Bytes) return;
            part.Position = 0;
            byte[] hash;
            using (var sha = SHA256.Create()) hash = sha.ComputeHash(part);
            part.Dispose();
            part = null;
            if (!((ReadOnlySpan<byte>)hash).SequenceEqual(offer.Sha256)) { File.Delete(partPath); WarLog.Warn(LogCategory.Replay, "replay transfer failed its hash check"); return; }
            string final = partPath.Substring(0, partPath.Length - ".part".Length);
            File.Move(partPath, final);
            Saved?.Invoke(final);
        }

        public void Cancel()
        {
            if (part == null) return;
            part.Dispose();
            part = null;
            if (File.Exists(partPath)) File.Delete(partPath);
        }
    }
}
```

```csharp
public sealed class ReplayCursor : IDisposable
{
    private readonly string path;
    private FileStream file;
    private ReplayReader reader;
    private bool havePending;
    private int pendingTick;
    private ReplayChannel pendingChannel;
    private byte[] pendingBytes = new byte[0];
    private int pendingLength;

    public ReplayHeader Header { get; private set; }
    public float Seconds { get; private set; }
    public float DurationSeconds { get; }
    public string Error => reader?.Error;

    public ReplayCursor(string path)
    {
        this.path = path;
        int last = 0;
        Open();
        while (reader.TryNext(out int t, out _, out _)) last = t;
        DurationSeconds = last * Header.TickSeconds;
        Restart();
    }

    private void Open()
    {
        reader?.Dispose();
        file = File.OpenRead(path);
        if (!ReplayReader.TryOpen(file, out reader, out string error)) { file.Dispose(); throw new InvalidDataException(error); }
        Header = reader.Header;
    }

    public void Restart() { Open(); Seconds = 0f; havePending = false; }

    /// <summary>Applies every record whose tick time is ≤ <paramref name="seconds"/>, in order. Never goes back (use <see cref="Restart"/>).</summary>
    public void AdvanceTo(float seconds, Action<int, ReplayChannel, ArraySegment<byte>> apply)
    {
        if (seconds < Seconds) return;
        Seconds = seconds;
        while (true)
        {
            if (!havePending)
            {
                if (!reader.TryNext(out pendingTick, out pendingChannel, out ArraySegment<byte> p)) return;
                if (pendingBytes.Length < p.Count) pendingBytes = new byte[Math.Max(p.Count, pendingBytes.Length * 2)];
                Array.Copy(p.Array, p.Offset, pendingBytes, 0, p.Count);
                pendingLength = p.Count;
                havePending = true;
            }
            if (pendingTick * Header.TickSeconds > seconds) return;
            havePending = false;
            apply(pendingTick, pendingChannel, new ArraySegment<byte>(pendingBytes, 0, pendingLength));
        }
    }

    public void Dispose() { reader?.Dispose(); reader = null; }
}
```
