# v0.17 Heartland Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every map a middle worth fighting over: a rich gem tile, generated only in central areas, that a Miner mines for 2.5 times the ordinary rate, for good, with the AI valuing it.

**Architecture:** A new `TileType.RichGem` (value 6) behaves as an ordinary gem everywhere (a shared `TileRules.IsGem` replaces the `== TileType.Gem` checks) except in what it pays: `MinerRules.RateOf` gives the Miner payout multiplier and the dig stage pays `RichGemPayout`. `RegionMapGenerator` grows rich veins in central areas far (by lane distance) from every start site after the ordinary gems. The client draws it with a new `RenderGen.RichGem` tile set and a minimap colour; the AI's view gains per-region gem worth, which the opening, expansion and target scoring read.

**Tech Stack:** Unity 6000.4.1f1, Unity Entities (DOTS) sim, Mirror, UI Toolkit, NUnit (EditMode and PlayMode through `tools/unity-test.sh`), the control API (`tools/war2d`).

**Spec:** [docs/superpowers/specs/2026-11-01-v0.17-heartland-design.md](../specs/2026-11-01-v0.17-heartland-design.md) (approved 2026-11-01 with the default open decisions D1 to D4).

## Global Constraints

- Branch `release/v0.17` (cut from `release/v0.16` at 4a2ec85; v0.16's PR #23 is still open). Never commit from `main`. No co-author or "Generated with" lines in commits or PRs (CLAUDE.md).
- `TileType.RichGem = 6`, after `WallBlueprint`, so existing values keep their numbers.
- Payout: a Miner facing a rich gem earns `<Resources><MiningRate>` × `<Resources><RichGemMultiplier>` = 10 × 2.5 = **25/s**, endless.
- Digging a rich gem pays `<Siege><RichGemPayout>` = **375** once; the tile becomes ground (D1).
- Generator: `<Map><CentralRichGemTiles>8 16 24 32</CentralRichGemTiles>` per `LayoutSizes` row per central area, 2 to 4 clusters per area; `<Map><RichMinStartDistance>0.15</RichMinStartDistance>` (lane distance, share of map size); central areas only (D3); at least one rich field on every map.
- Sight: a rich gem blocks sight exactly as an ordinary gem does (today: it doesn't; `TileRules.BlocksSight` lists rock, player walls and border only).
- The AI gets no special rush rule (D4); its policy's expansion timing and defence decide.

private static long NearestStart(MapLayout l, int region)
{

        private const byte RichGem = (byte)TileType.RichGem;

        /// <summary>
        /// The shortest lane distance (sum of <see cref="MapLane.Length"/>) from region <paramref name="from"/> to every region
        /// (<see cref="long.MaxValue"/> when unreachable). Dijkstra over the plan's few regions; v0.17 rich-field placement and
        /// the fairness tests use it.
        /// </summary>
        public static long[] LaneDistances(MapRegion[] regions, MapLane[] lanes, int from)
        {
            int n = regions.Length;
            var dist = new long[n];
            var done = new bool[n];
            for (int i = 0; i < n; i++) dist[i] = long.MaxValue;
            dist[from] = 0;
            for (int step = 0; step < n; step++)
            {
                int u = -1;
                for (int i = 0; i < n; i++) if (!done[i] && dist[i] != long.MaxValue && (u < 0 || dist[i] < dist[u])) u = i;
                if (u < 0) break;
                done[u] = true;
                foreach (MapLane l in lanes)
                {
                    int v = l.A == u ? l.B : l.B == u ? l.A : -1;
                    if (v >= 0 && dist[u] + l.Length < dist[v]) dist[v] = dist[u] + l.Length;
                }
            }
            return dist;
        }

        /// <summary>
        /// The central areas that get rich gems (v0.17): every one whose lane distance to its nearest start site is at least
        /// <c>RichMinStartDistance</c> × size; if none is, the one farthest from its nearest start (so every map has one).
        /// </summary>
        public static List<int> RichAreas(MapRegion[] regions, MapLane[] lanes, int size, MapConfig cfg)
        {
            long min = (long)(cfg.RichMinStartDistance * size);
            var chosen = new List<int>();
            int farthest = -1;
            long farthestD = -1;
            var nearest = new long[regions.Length];
            for (int i = 0; i < regions.Length; i++) nearest[i] = long.MaxValue;
            for (int s = 0; s < regions.Length; s++)
            {
                if (regions[s].Kind != RegionKind.Start) continue;
                long[] d = LaneDistances(regions, lanes, s);
                for (int i = 0; i < regions.Length; i++) nearest[i] = math.min(nearest[i], d[i]);
            }
            for (int c = 0; c < regions.Length; c++)
            {
                if (regions[c].Kind != RegionKind.Central) continue;
                if (nearest[c] >= min) chosen.Add(c);
                if (nearest[c] != long.MaxValue && nearest[c] > farthestD) { farthestD = nearest[c]; farthest = c; }
            }
            if (chosen.Count == 0 && farthest >= 0) chosen.Add(farthest);
            return chosen;
        }

        /// <summary>
        /// Grows <paramref name="count"/> rich gem tiles in 2 to 4 clusters on the rock faces of a central area (v0.17), the
        /// clusters spread round the area so more than one side is worth holding. Only rock facing floor becomes rich gem
        /// (never the border, which is written after; never an ordinary gem, which stays).
        /// </summary>
        private static void AddRichField(NativeArray<byte> tiles, int size, MapRegion region, int count, ref Random rng)
        {
            int clusters = 2 + rng.NextInt(0, 3);
            int left = count;
            float turn = rng.NextInt(0, 360) * math.PI / 180f;
            for (int k = 0; k < clusters && left > 0; k++)
            {
                int share = k == clusters - 1 ? left : count / clusters;
                float a = turn + k * 2f * math.PI / clusters;
                int2 at = region.Centre + (int2)math.round(new float2(math.cos(a), math.sin(a)) * region.Radius * 0.6f);
                left -= GrowRich(tiles, size, at, region.Radius / 2 + 4, share, ref rng);
            }
        }
